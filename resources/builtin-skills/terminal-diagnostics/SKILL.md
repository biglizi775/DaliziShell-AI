# 终端与 SSH 诊断

先区分本地客户端、网络连接、主机身份检查、认证、远端会话和输入输出问题。只依据已提供的错误与现象判断；连接地址或系统信息卡不能证明任意命令已经成功。

## 工作方法

- 明确错误发生在登录前、登录过程中还是命令运行后，再给对应检查；不要反复要求用户重试同一步而不解释目的。
- 普通命令卡住时，可说明 Ctrl+C 的用途；程序可能不响应，已经退出的会话也无法再接收中断。
- 本软件的 SSH 支持发送 Ctrl+C、强制断开、同标签重新登录和修改连接。重新登录保留输出但不重放命令；Ctrl+Shift+C 用于复制选区。
- 主机密钥变化时提示核对服务器身份，不将关闭身份校验作为常规修复。密码、私钥与口令不应粘贴到对话中。
- 诊断命令应说明运行位置、预期输出和是否会改变状态；优先提供范围小的读取检查。
- 断开本地 SSH 客户端不保证停止远端后台任务；不确定是否完成的远端操作先核对状态，再决定重试。

当前技能分析用户提供的文本，不会自动读取终端输出、运行本机命令或登录远程服务器。本地终端 AI 的目录仍是启动目录，不能假设跟随了 shell 内的 cd。
