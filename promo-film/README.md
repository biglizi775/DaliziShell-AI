# 呆梨文件 · Studio 真实界面宣传片

基于本项目 **v0.5.1** 制作的 96 秒产品宣传动画。画面、界面、图标、转场、配乐和音效全部由代码生成，没有使用外部图片、视频、录音、在线字体或生成式媒体素材。界面帧来自本项目 HTML/CSS/JS 的程序化渲染，保存为 PNG 后由 Canvas 做镜头与转场。它是独立宣传演示，不会访问本机文件、连接 SSH 或调用 AI 接口。

## 播放

在本目录运行 `npm start`，打开终端显示的 `http://127.0.0.1:4173`。也可以在项目根目录运行 `npm run promo`。网页无构建步骤、无运行时第三方依赖，`dist/` 可部署到任意静态服务。

点击「播放影片」启用音频；配乐在浏览器内生成。支持暂停、跳转、八章导航、全屏、静音、WAV 下载与 WebM 录制。快捷键：空格暂停，左右键跳转五秒，M 声音，F 全屏。网页录制要求浏览器支持 MediaRecorder，录制时保持页面前台，耗时约 96 秒。手机适合预览，细节观看建议桌面全屏。

## 成片输出

`npm run render` 逐帧生成 **1920 × 1080 / 60 fps / 96 秒 / H.264 + AAC** MP4，同时导出 48kHz 双声道 WAV。帧号直接决定时间，渲染速度不影响成片帧率；不使用屏幕录制。

需要项目根目录已有的 Playwright、Windows Edge，以及 FFmpeg。默认通过 Python `imageio_ffmpeg` 查找 FFmpeg，也可设置 `FFMPEG` 环境变量为可执行文件路径。可用 `FPS=30`（PowerShell：`$env:FPS='30'`）减少导出耗时。若在其他系统运行，请将工具中的 `channel:'msedge'` 改为已安装的浏览器。

输出位于 `output/`：

- `dalizi-files-real-ui-1080p60.mp4`：最终成片。
- `dalizi-original-score.wav`：程序合成配乐。
- `render-report.json`：分辨率、帧数、时长与输出信息。
- `web-preview.png`、`frame-*.png`：播放器与关键帧检查图。

`npm run verify` 验证章节跳转、进度控制、音频合成、播放/暂停/静音、影片结束、移动端宽度和所有章节的渲染，并输出 `verification.json`。

## 项目分析与分镜

主叙事是「减少工作上下文切换」。宣传中的具体能力来自根目录 README、`docs/USER_GUIDE.md` 与现有 UI，未把开发规划作为已实现功能。

| 时间 | 内容 | 体现的便利性 |
| --- | --- | --- |
| 00–12s | 分散的文件与窗口汇聚成品牌 | 从工作碎片进入统一工作区 |
| 12–24s | 文件、PowerShell、网页标签切换 | 在同一个窗口保持工作脉络 |
| 24–36s | 双面板、多选、确认复制、文件飞行 | 来源与去向同时可见 |
| 36–48s | 条件搜索、定位、PDF 与表格预览 | 找到文件后直接阅读 |
| 48–60s | 服务器资源、终端、SFTP 下载 | 登录后进入完整远程工作区 |
| 60–72s | 当前目录、AI 计划、确认与复制 | 以目录为范围，操作前明确确认 |
| 72–84s | 技能、显式保存目录记忆、历史恢复 | 项目工作能够接续 |
| 84–96s | 功能汇聚与片尾 | 「少一点切换，多一点心流」 |

第二版已将暖白、墨黑、金色视觉落地为真实软件的 Studio 默认主题；设置 → 界面与浏览 → 界面风格可切回经典，且可独立切换深浅主题。宣传片直接渲染这个版本的实际 UI，不再自绘替代控件；文件、主机、统计值与对话均为演示数据。保留真实 `d·` 品牌符号；软件与宣传片使用同一套暖白、墨黑、金色与低饱和绿色视觉。没有虚构效率提升数字。AI 演示不暗示任意代码执行、自动读取全部文件或无需配置；技能是工作流说明。PDF/Office 预览边界、SSH 服务端要求与 AI 接口配置以项目文档为准。

## 动画与声音实现

- `dist/film.js`：确定性时间轴、代码粒子、轨道收拢、品牌排版、方向遮罩转场和章节进度。
- `dist/scenes-actual.js`：真实应用画面、确定性相机推进、聚焦、光标与操作转场。
- `dist/actual-ui/`：由应用代码自动渲染的各操作状态、分镜清单和来源哈希；`scenes-local.js` / `scenes-connected.js` 是第一版概念片的保留源码，不再用于当前成片。
- `dist/audio.js`：种子化程序配乐，和声、低音、节拍、琶音、混响及动作提示音，详见 `SCORE.md`。
- `dist/player.js`：播放时钟与音频偏移同步，Seek 时重建音源，浏览器录制和配乐下载。
- `dist/kit.js`：Canvas 图形、图标、排版与缓动基础。

所有场景可随机访问任一时刻；画面不依赖上一帧状态。代码使用系统中文字体，不下载字体。应用新增 `studio-theme.css` 和 `studio-panels.css`；风格选择与明暗主题独立，经典主题保持可用。

## 同步真实界面

修改应用界面后，在仓库根目录运行 `npm run promo:assets`。脚本加载实际 `ui/index.html`、CSS、JS，使用只在浏览器测试环境内生效的 Tauri 模拟后端，再通过真实交互生成界面帧；不会读取用户目录、连接服务器或发送模型请求。`build-storyboard.cjs` 记录前端源文件的 SHA-256，便于核对成片与应用版本。随后执行 `npm run promo:verify` 和 `npm run promo:render`。不要直接修改生成的 PNG 来制造应用中不存在的界面。
