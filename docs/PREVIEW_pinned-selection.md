# 固定项目时引用子目录选中项

在 Agent 面板固定项目 A 并开启「项目工具」。浏览 A 的子目录、选中文件时，面板会列出「子目录选中项」。要在下一条消息中附上它们，请点击「本次引用」，并在「本次引用」栏核对相对于 A 的路径。发送后，再次提问可以重新选择。

只刷新目录且选中项相同，已选的引用会保留。改选文件、切走标签或离开目录会清除这次选择。回到 A 的根目录时，仍可直接使用当前选中项；右键文档选择「让 Agent 修改…」仍会引用你明确点选的文档。

此调整适用于普通 Agent 的「项目工具」。该模式仍允许按项目权限读取目录。只需发送几份文件的快照时，可使用「文件任务」核对要发送的内容。
