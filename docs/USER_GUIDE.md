# 使用手册

一个用 **Rust + Tauri 2** 打造的 Windows 智能体工作台：文件浏览与预览、快速搜索、AI 对话、技能与目录记忆，以及 PowerShell、SSH 和 Chromium 网页标签。前端保持原生 HTML/CSS/JavaScript，支持中英文。

开发规划见 **[智能体工作台开发方案](AGENT_WORKBENCH_DEVELOPMENT.md)**：汇总已实现能力、首批内置技能与后续 Agent 角色、工具执行层、电脑/浏览器操控、会话与任务恢复，以及各项增强的优先级、依赖和验收标准。规划功能尚不等于当前程序能力。

## 最小化到系统托盘

程序运行时会在 Windows 通知区域显示呆梨图标。点击标题栏的最小化按钮，窗口收起到托盘，当前文件标签、PowerShell/SSH 会话及正在执行的任务继续保留。

- 单击托盘图标恢复并聚焦窗口；最大化窗口收起后恢复最大化状态。
- 右键托盘图标可选择“显示窗口”“最小化到托盘”“退出程序”。
- 图标可能位于任务栏右下角的“显示隐藏的图标”（`^`）中，位置由 Windows 管理。
- 标题栏的关闭按钮仍然退出程序。托盘“退出程序”同样执行终端、浏览器与缓存的退出清理。
- 如果系统无法创建托盘图标，程序保留普通任务栏最小化，避免窗口隐藏后无法找回。

## 为什么快

- 目录枚举直接走 Win32（`FindFirstFileExW` + `FIND_FIRST_EX_LARGE_FETCH`），一次调用同时拿到名称/大小/时间/属性，不做逐文件 stat；
- 前端**虚拟化列表**，只渲染可见行及少量缓冲行，降低大目录的 DOM 开销；
- UI 为纯静态 HTML/CSS/JS（WebView2 渲染），由 Rust 后端提供全部系统调用。

## 收藏夹栏与上次工作区

地址栏下方新增收藏夹栏。打开本地文件夹或网页后点击 `☆` 收藏当前位置；已有侧栏固定目录会首次导入，侧栏快速访问继续保留。单击收藏跳转到已有标签，没有打开时创建新标签；Ctrl+单击、中键或右键“在新标签页打开”可另开一份。右键提供编辑、左移、右移和移除；栏末 `•••` 或“设置 → 收藏与启动”可以添加完整路径/网址、修改名称、筛选收藏及隐藏收藏栏。最多 100 项，支持普通盘符、UNC 文件夹、HTTP/HTTPS 与空白网页，不保存网址中的用户名/密码。

“收藏与启动”中的“记住打开的标签”保存最多 50 个文件夹/网页标签的地址、标题、顺序和选中位置。默认启动时自动恢复；曾关闭旧版浏览器恢复的用户沿用关闭偏好。也可关闭自动恢复，通过收藏栏 `↶` 或设置中的“立即恢复上次标签”手动恢复，本次已恢复后不会重复添加，已打开的相同位置会复用。窗口最小化到托盘不算退出，也不会重建标签。

后台网页在选中后才加载；缺失目录、网络不可达或网页失败保留可重试的标签。恢复不包含终端/SSH 连接、正在运行的任务、AI 聊天、网页表单、登录凭据和网页前进后退栈，也不恢复多个独立程序窗口的位置/大小。文件夹的 AI 工作范围仍跟随对应标签路径。

会话与收藏保存于当前 Windows 用户的应用 WebView2 本机存储。关闭“记住打开的标签”清除会话记录并停止保存；关闭“记录网页访问历史”会从当前和上次会话快照中移除网址、停止新增网页快照，文件夹恢复与主动收藏继续保留。浏览器设置中的恢复开关与工作区设置共用；“清除浏览数据 → 上次网页标签快照”只清除网页快照。清除记录不会关闭当前标签，继续导航时可能重新生成记录。

## AI 上下文与长期记忆整理

对话输入框上方显示聊天上下文的字符数、近期消息数和估算 Token 数，可展开查看摘要或点击“立即压缩”。自动压缩默认开启：发送前，未摘要的历史超过 12 条或摘要与历史合计达到 18,000 字符时，将较早消息发送到当前配置的模型生成摘要，尽量保留最近 6 条原文；长消息时至少保留最近 2 条。后续请求携带摘要及近期消息，聊天部分最多 24,000 字符、16 条近期消息，摘要最多 6,000 字符。

摘要请求支持三种现有 API 格式，可取消，可能产生额外 Token 费用。摘要失败会显示提示，保留已有摘要和原对话，并使用预算内的近期历史继续回答；修改模型、取消或关闭标签后，迟到摘要不会覆盖当前状态。估算数不是服务商实际用量，也不是所选模型的完整上下文窗口，不包含系统提示、目录元数据、技能和长期记忆。

压缩不会主动删除可见消息；本次会话仍沿用最多 60 条可见消息的限制。聊天摘要只在当前应用会话内使用，不自动写入目录长期记忆。新对话清空该对话的摘要；摘要不授予文件操作权限，模型仍需遵循当前权限模式与目录边界。

“技能 / 记忆 → 记忆”新增条数、启用条数、正文大小、估算 Token 和重复项统计。对话前自动整理当前目录的长期记忆，或点击“立即整理重复记忆”：只合并正文完全相同、启用状态相同的重复项，保留最新条目和其他原文，不对用户偏好做语义改写。无重复项不写文件，未创建记忆的目录不会因此新增 `.dalizi`。

实际整理前，将完整旧记忆备份为当前目录 `.dalizi/agent-memory-backup-*.json`，再原子更新 `.dalizi/agent-memory.json`。备份可以通过现有“导入记忆”入口选择、核对后恢复（导入项默认停用）；备份保留在目录内，不自动删除。只读、损坏或不可用的记忆会提示错误。两个自动整理开关都在记忆面板中，可分别关闭。

## 功能

- **全新工作空间界面**：固定侧栏、分层工具栏、常用位置入口、磁盘容量卡片和最近访问目录；默认浅色，可切换深色并记忆偏好
- **文件类型筛选**：全部 / 文件夹 / 图片 / 文档，可与当前目录搜索组合；筛选会清理不可见的选择，避免误操作
- **预览与详情面板**：选择文件后按空格或点预览按钮，优先阅读内容，展开“文件属性”查看完整路径、类型、大小、修改/创建/访问时间及系统属性；支持 PNG/JPEG/GIF/WebP 图片、文本/代码、PDF、Word OOXML 文档和常见表格
  - Rust 只读加载：图片最多 8 MiB，文本最多 64 KiB；支持 UTF-8、UTF-16 BOM，超长文本明确标注截断
  - PDF 最多 32 MiB：内置 [Mozilla PDF.js](https://github.com/mozilla/pdf.js) 6.4.299，支持翻页、指定页码、适合宽度、缩放及加宽阅读。按需绘制单页、限制画布大小；切换文件释放解析与绘图资源。同目录自动刷新不会重置未修改 PDF 的阅读位置。字体、CMap 和解码资源全部打包在本地，不依赖在线预览服务
  - Word `.docx/.docm/.dotx/.dotm` 最多 16 MiB：Rust 在后台解析正文、段落和表格文字，支持中文、UTF-16、严格 OOXML 命名空间和通过包关系指定的正文路径；正文输出最多 256 KiB，截断时提示。预览不还原图片、原始版式、页眉及脚注；不需要安装 Office，不执行宏。ZIP 部件、解压体积和 XML 深度有处理上限
  - 表格 `.xlsx/.xlsm/.xltx/.xltm/.xlsb/.csv/.tsv` 最多 32 MiB：工作表切换、行列标题、横向滚动，每页显示 50 行。Excel 使用 Rust [Calamine](https://docs.rs/calamine/0.36.1/calamine/) 的单元格流式读取，避免按虚假超大尺寸分配整表。预览最多 20 张表、每表前 500 行与 50 列、每单元格 4 KiB、全工作簿文字合计 2 MiB；截断会提示。显示已保存值，不计算公式、不执行宏或外部链接，不还原图表与完整格式。CSV 支持逗号/分号/制表符、引号内换行和 `sep=` 声明；文本支持 UTF-8、带 BOM 的 UTF-16，并对中文 Excel 导出尝试 GB18030
  - 加密 Office、损坏或超过上限的文档给出明确提示，可以点击“打开”交给关联程序处理
  - PDF 支持文件头前的 BOM/短前缀；加密 PDF 可在面板内输入密码，密码仅用于本次本地预览。组件加载失败与文档损坏分别提示
  - 文本按纯文本展示；SVG/HTML、设备、管道、链接及未知重解析类型不做内容预览。已缓存的 Windows Cloud 文件按打开句柄的标签校验；尚未下载的云文件提示先下载，不隐式触发下载。普通长路径/UNC 路径可识别。旧版 `.doc/.xls`、`.ods`、加密 Office 文档仍需关联程序或转换格式；不同失败原因显示具体提示
- **统一设置与快捷操作**：左下角“设置”集中管理主题、预览、显示列、模型接口、技能、记忆和浏览器设置；“设置 → 快捷操作”或 `Ctrl+K` 搜索操作、常用目录与打开的标签页，方向键选择、Enter 执行、Esc 关闭
- **键盘浏览**：方向键、Home/End、PageUp/PageDown 联动虚拟列表，Shift 扩展选择；列表/网格偏好自动保存
- **可定制表格列**：默认显示名称 / 修改日期 / 类型 / 大小；右键表头、文件或空白处 →“选择显示列”，可增加创建日期、访问日期、扩展名、属性、完整路径，勾选后“应用”保存。名称始终显示；提供默认显示列与取消按钮。拖动表头改变顺序，拖动边界调整宽度，双击边界自动适配。显示列、列宽和顺序自动保存，窄窗口可水平滚动，表头与文件行保持对齐。
- **文件与文件夹属性**：右键单个项目 →“属性”，查看 9 项信息和精确字节数，并可进入显示列设置；后台算出文件夹大小后，已打开的属性窗口同步更新。新增时间和属性直接使用现有 Win32 目录枚举结果，不增加逐文件查询；访问日期由文件系统维护，可能延迟更新。
- **统一搜索输入框**：顶栏同一输入框切换“当前目录 / 含子目录 / 全部位置”；当前目录即时筛选，其余模式查询持久化文件名索引，在输入框下方显示结果，不再弹出第二个输入框。`Ctrl+Shift+F` 切到全部位置并聚焦输入框。索引搜索支持多词、引号词组、扩展名、路径与文件/文件夹过滤；结果可双击打开、在系统资源管理器中定位或复制路径。切换目录或标签页会清除旧关键词和结果，迟到结果不覆盖新范围。
- **独立 Agent 对话**：对话停靠在整个文件工作区或 PowerShell 终端的最右侧，与文件预览同时使用；右上角“AI 对话”或快捷操作面板可打开。工作目录始终跟随当前标签页，不再单独固定路径。每个标签页的对话、草稿与权限独立；同一标签页切回曾浏览的目录会恢复本次运行中的聊天。消息、待确认操作和执行结果在同一条对话中展示。
  - 面板可拖动边界调宽、收起，也可点标题栏“浮动对话窗口”，在应用内拖动和缩放，再停靠回右侧。显示状态、宽度及浮动位置会记忆；浮动窗口仍位于当前应用内，不是独立的系统窗口。
  - 选中文件会显示为本轮上下文，可点击“忽略选择”；`Enter` 发送，`Shift+Enter` 换行，支持中文输入法。
- **内置/自定义技能和目录记忆**：对话上方“技能 / 记忆”进入独立管理窗口；随程序提供 9 项基础技能，也支持导入自己的 `SKILL.md`。可启停技能、查看能力范围、编辑当前目录 `.dalizi/agent-memory.json` 中的记忆，并显示本轮回复实际使用的技能与记忆数量。学习模式默认关闭，开启后先提出记忆建议，核对保存后才写入当前目录。浏览目录不会自动创建记忆文件。
- **三种 AI 权限模式**：输入框下方选择“只读 / 确认后执行 / 自动执行（当前目录）”，默认确认后执行。模式变化会取消正在生成的回复并作废旧计划；Rust 后端独立校验权限，自动模式也保留当前目录边界和不覆盖限制。

- **浏览器式多标签页**：新建 / 关闭 / 切换 / 中键关闭 / 右键菜单（复制标签页、关闭其他），每个标签页独立历史
- **嵌入式 PowerShell 终端标签页**：标签栏 `> _` 按钮或右键"在终端中打开"，基于 Windows ConPTY + xterm.js，真彩色、交互式（ps1/pwsh 自动选择），起始目录为当前文件夹，随窗口自适应行列
- **SSH 连接标签页**：页头或标签栏“SSH”新建独立连接，可与多个 PowerShell、SSH 和文件标签同时使用。支持主机名、IPv4/IPv6、端口、用户名、私钥路径及保存连接；登录后在终端上方显示连接地址、服务器 IP、系统和运行时间。支持发送 Ctrl+C、强制断开、同标签重新登录并保留输出，也可复制标签开启另一条独立连接。
- 浏览 / 后退 / 前进 / 上一级 / 面包屑（可点击、可直接输入路径，过长自动滚动到末尾显示）
- 文件夹可**固定/取消固定到快速访问**（右键菜单）；侧栏**最近访问**自动记录（最多 8 个，可移除）
- 详情列表视图（名称/修改日期/类型/大小，点击列头排序）+ 网格视图，可切换
- 文件操作：复制 / 剪切 / 粘贴 / 重命名（F2）/ 删除（进回收站）/ 新建文件夹
  - 复制移动删除走系统 `IFileOperation`：原生进度、冲突确认、可撤销
- **持久化目录大小索引**：目录列表直接携带内存索引中的大小，前端在第一次渲染时展示已有数值；刷新不清空旧值。大小和文件名索引分别保存到应用缓存目录的 `folder-sizes-v1.json`、`file-names-v1.json`，启动时优先恢复。距上次完整后台校验不足 10 分钟时，先复用缓存并启用监听，剩余窗口结束后执行一次后台校验；较旧或缺失缓存立即开始后台校验。首次没有缓存的目录仍需扫描，期间显示“计算中…”；不可读目录显示“不可用”，已有数值则保留，UNC 网络路径与符号链接/junction 默认跳过。
  - 每块固定盘使用递归监听，变化后重算受影响目录及祖先；监听器溢出触发重建。缓存值可能短暂落后于文件变化，后台计算完成后自动更新。
  - 当前目录的补算使用单个工作线程与可替换队列，快速切换目录会取消旧任务；后台目录枚举串行执行，降低并发磁盘争抢。前端按帧合并结果，仅更新可见行，按大小排序时合并重新排序。
  - `F5` / 刷新按钮主动重新计算当前列表中的文件夹，等待时仍显示原值。状态栏显示“后台索引中…”提示。
  - 后台校验逐级核对直接子项的名称、类型、大小和时间，未变分支复用已验证总量；不以父目录修改时间代替对子目录的检查。退出期间的变化可能在下次校验前短暂显示为旧缓存，可用 `F5` 或搜索面板“重新校验索引”主动更新。
- 侧栏：**最近访问**（自动记录，最多 8 个）+ 快速访问（桌面/文档/下载/图片/音乐/视频）+ 此电脑（含磁盘容量条）
- 文件夹变更实时监听（`ReadDirectoryChangesW`），外部变化自动刷新
- 本目录即时筛选搜索；显示/隐藏隐藏项
- 双击打开（关联程序）、"打开方式…"、在资源管理器中显示、复制完整路径（含文件名和扩展名）：选中文件/文件夹后右键或工具栏“更多” →“复制完整路径”，也可按 `Ctrl+Shift+C`。多选时每行一个路径，原样保留中文和空格，不添加引号；预览面板复制按钮同样可用。
- 中英文一键切换；偏好（主题/预览面板/语言/视图/排序/上次位置）自动记忆

## 快速搜索与 AI 使用

搜索示例：`报告 2026`、`ext:pdf;docx 合同`、`type:dir 项目`、`path:Downloads 安装`。搜索默认忽略大小写，多个条件取交集；按空格分词，需要连续词组时使用双引号。界面每次显示前 200 项，结果过多时增加关键词；首次索引尚未完成、目录无权限或达到 100 万项上限时，结果并不覆盖全部文件。

搜索采用“预先建立本地文件名索引，输入时查询内存”的方式，后台复用大小扫描收集元数据，不会为每次搜索重新递归磁盘。设计参考 [Everything 的文件名索引思路](https://www.voidtools.com/en-uk/faq/)；本版使用普通权限的目录枚举和变化监听，不包含其 NTFS MFT/USN 服务模式，不承诺相同的首次全盘建库速度。

在 AI 设置中先选择 **API 格式**，再填写基础地址、模型和密钥；旧配置自动沿用 Chat Completions。

| API 格式 | 地址示例 | 实际请求与认证 |
| --- | --- | --- |
| OpenAI Chat Completions | `https://your-api.example/v1` | `/v1/chat/completions`，Bearer Key |
| OpenAI Responses | `https://your-api.example/v1` | `/v1/responses`，Bearer Key |
| Anthropic Messages | `https://api.anthropic.com` | `/v1/messages`，`x-api-key` 与 `anthropic-version: 2023-06-01` |
| DeepSeek 的 Anthropic 兼容入口（选择 Messages） | `https://api.deepseek.com/anthropic` | `/anthropic/v1/messages` |

可以填写与所选格式匹配的完整请求地址，不重复拼接路径；完整地址与格式冲突时提示修正。远程接口要求 HTTPS；本机模型服务可以使用 localhost / 回环 IP 的 HTTP。API Key 仅在本次应用会话内存中保存，地址、模型、格式和推理偏好会记忆。不会自动猜测协议、降级到另一种格式或把密钥转发到重定向地址。

配置思路参考 [DeepSeek Harness 的自定义模型 API](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/guide/providers.md)，请求结构依据 [OpenAI Responses](https://developers.openai.com/api/reference/typescript/resources/responses/methods/create)、[Anthropic Messages](https://platform.claude.com/docs/en/api/messages) 和 [DeepSeek Messages](https://api-docs.deepseek.com/api/create-message/)。保持 Rust/Tauri 与原生前端，不引入这些项目的运行框架。

点击对话面板顶部“设置”，在独立窗口中填写“连接模型 / 访问凭据”。窗口实时显示实际请求地址，支持密钥显隐、字段校验和未保存状态；底部“保存并返回”应用配置并显示成功提示，“取消”或 Esc 放弃修改。保存不会主动发送测试请求，窄窗口中底部按钮保持可见。

点击 **测试 API**可在保存前测试当前表单中的地址、格式、模型、密钥及推理参数。测试发送一条固定短消息，可能产生少量模型调用费用；不读取或发送目录、选中文件、技能、记忆、对话历史，也不执行文件动作。只有 HTTP 成功且解析到对应格式的非空文本才显示成功、耗时、模型和实际地址；HTTP 401/403/404/429、重定向、超时、格式错误及截断会分别提示。

修改表单、取消测试或关闭设置会丢弃旧结果；保存与测试相互独立。测试接收超时 30 秒，响应读取预算 45 秒；取消会立即使界面结果失效，已进入 WinHTTP 的阻塞调用仍需等待完成或超时，服务端可能继续计费。测试成功说明当前模型能返回文本，不保证模型一定遵守文件操作计划格式。未配置真实密钥时，仅可运行本机样本验证。

三类协议目前都采用非流式文本对话；Responses 显式发送 `store:false` 并每次携带本地历史；Messages 使用顶层 system 与 4096 输出 token 上限。思考内容/工具调用不会误作最终文本，截断回复不会成为可执行计划。

配置后在对话底部输入消息并发送。每次发送会提供当前工作目录、最多 200 条直接子项元数据、最多 20 个选中项的元数据以及最近对话，不自动发送文件正文。可以先询问目录情况或讨论整理方案，模型无需每轮都提出文件操作。

### 技能与记忆

点击对话上方“技能”，在“内置技能 / 我的技能”中选择要用于下一轮对话的工作流。9 项内置技能编译进程序，可离线查看；默认关闭，不会自动替换已有的用户选择。内置与自定义技能**合计最多启用 4 个**，自定义技能仍最多保存 32 个，内置目录不占用这 32 个名额。

| 内置技能 | 当前用途 |
| --- | --- |
| 文件整理 | 根据目录/选中条目元数据给出整理计划；可使用现有新建目录、重命名、移动和文件复制动作 |
| 任务拆解 | 目标、步骤、依赖与验收方案 |
| 产品与交互设计 | 产品流程、设置交互、状态与错误恢复设计建议 |
| 界面设计评审 | 基于提供材料评审层级、布局、键盘与窄窗体验 |
| 软件开发建议 | 分析用户提供的代码或需求，给出修改与验证建议 |
| 调试与测试建议 | 分析提供的日志，提出复现、定位与测试步骤 |
| 代码审查建议 | 审查提供的代码或差异，给出可核实的问题与建议 |
| 文档编写 | 在对话中生成 README、开发方案与操作说明草稿 |
| 终端与 SSH 诊断 | 分析用户提供的终端错误及恢复方式 |

除文件整理可复用现有文件动作外，其余内置项标为“分析与建议”。技能不会增加自主读取文件正文、写代码、运行测试、联网浏览或电脑操控能力，也不改变当前权限。实际执行层和角色切换仍按开发文档规划。内置项显示来源与版本，可以查看正文、启停；不能直接移除或修改内置正文。

导入自己的技能时，选择 `SKILL.md` 或输入包含它的本地文件夹路径，再点击“导入技能”。导入后勾选“用于对话”，下一轮即附加说明。支持常见的 `name` / `description` YAML 头部以及纯 Markdown 说明，例如：

```markdown
---
name: 项目归档规范
description: 按项目、年份和资料类型整理文件
---
先了解当前目录和用户要求，再提出整理计划。
日期统一使用 YYYY-MM-DD；保留原始文件名中有意义的项目编号。
```

技能组织方式参考 [OpenAI Skills 文档](https://developers.openai.com/plugins/concepts/skills)。用户导入的技能说明保存为本地快照；同一路径重新导入可更新，移除技能不删除源文件。单个文件最多 64 KiB，启用技能的上下文合计最多 32 KiB；超出时会提示截断。当前加载说明正文，不自动读取关联资料或执行技能附带脚本；技能不会增加文件操作权限。

点击“记忆”可添加、编辑、启停和删除偏好，保存位置固定为该标签页当前目录下的 `.dalizi/agent-memory.json`。例如浏览 `D:\项目A` 时保存到 `D:\项目A\.dalizi\agent-memory.json`，切到 `D:\项目B` 后读取项目 B 自己的文件。两个标签页打开相同目录时共享该记忆文件，对话和权限仍独立。每次请求重新读取磁盘上的记忆，子目录不会自动继承父目录记忆；目录移动后，随目录一起移动的记忆文件仍可使用。

每个目录最多保存 100 条，每条最多 2000 个字符；请求中的记忆合计最多 8 KiB，优先使用近期更新的内容。关闭“在对话中使用记忆”后，已保存内容保留，但下一轮不会附加。记忆文件损坏时保留原内容并显示错误，可修复后刷新，或关闭使用记忆后继续对话；无权限或只读时明确提示保存失败，不改存到其他目录。

在“学习模式”中打开“从对话中提出记忆建议”，模型可从明确表达的长期偏好中提出最多 3 条建议。点击对话中的“编辑并保存”后，可修改内容并核对固定的目录位置；保存成功才进入该目录记忆。也可以用消息下方“存入记忆”手动保存。这是可编辑的上下文记忆，不会训练或修改模型参数。

用户技能快照、内置技能启停与通用开关继续保存在应用数据目录的 `agent-profile-v1.json`，位置不变，内部数据格式升级为 v2。读取旧 v1 配置不会写盘；首次修改时先备份原始 v1 内容，再原子保存新版。自定义技能、原有启停和记忆数据保留，损坏、外部冲突或写入失败时不覆盖原配置。旧版程序不能直接读取 v2；需要回退时保留当前配置，再使用迁移时生成的 v1 备份。内置正文来自程序资源，不写入用户配置。

迁移备份与原配置同目录，文件名为 `agent-profile-v1.json.v1-backup-migration-*.json`。当前冲突检查针对首次从 v1 迁移时的外部变化；并非完整的多进程配置合并机制，请退出旧版后使用新版。

目录记忆单独保存到所在目录，重启后继续可用。旧版集中存储的全局记忆和匹配当前目录的旧记忆会列在“旧版记忆”中，需勾选并点击“复制所选到此目录”才迁移，源数据保留。浏览、切换目录和打开管理窗口不会自动创建 `.dalizi`；显式保存或迁移才创建。发送消息时，启用的技能说明和当前目录记忆会发送给配置的模型服务。以上文件不保存 API Key 或完整聊天记录。

聊天与草稿按“标签页 + 当前目录”隔离，仅保留在本次应用运行中（最多缓存 24 组会话，正在处理的会话不强制淘汰，每组最多 60 条消息）；请求携带较早对话摘要与最近最多 16 条历史，聊天部分总计最多 24,000 字符。关闭标签会取消其待生成回复并释放待执行计划。终端标签页使用其启动目录作为上下文，界面明确显示“终端启动目录”，目前不追踪 PowerShell 内部 `cd`。

权限模式位于对话输入框下方，其审批与目录边界的区分参考 [OpenAI 的权限与沙箱说明](https://learn.chatgpt.com/docs/sandboxing)，本软件提供以下明确行为：

| 模式 | 行为 |
| --- | --- |
| 只读 | AI 只分析、回答；即使模型返回文件操作，后端也会阻止。用户手动保存记忆仍可使用。 |
| 确认后执行（默认） | 展开计划核对源/目标路径，勾选确认框并点击“确认执行”后才开始。 |
| 自动执行（当前目录） | 用户主动选择后，后续请求的有效计划可自动执行；仅支持当前目录内的新建、移动、重命名和文件复制。 |

每份计划最多 20 项操作。切换模式、发送新消息、修改接口设置或开启新对话会使旧计划失效。自动模式不持久化到新标签或重启；切换标签/目录期间返回的计划保留在原会话，须重新核对确认，不会在后台自动执行。历史建议不会被当作已经执行，实际执行结果会随下一轮对话提供给模型。

目前 AI 支持新建目录、文件/文件夹移动与重命名、文件复制；不执行删除、文件夹复制、任意脚本或终端命令。三种模式都以当前标签目录为范围，拒绝重解析点和覆盖；`.dalizi` 为记忆管理保留位置，不允许通过模型计划改动。执行前再次检查路径及源项目是否变化。单项失败会停止后续步骤，已完成的步骤不会自动回滚，界面会逐项报告结果。取消请求只适用于生成计划阶段。

## 稳定性与性能优化

- 文件复制、移动和删除异步执行，Shell 操作保留独立 STA 线程，等待原生对话框时不阻塞 Tauri 命令线程。
- 取消或部分中止移动时保留剪切记录；执行期间阻止重复提交粘贴/删除，完成旧操作不会清空后来复制的内容。
- 目录加载、刷新及目录大小查询校验请求版本与所属标签页，避免过期结果覆盖新目录或终端标签页。
- 刷新时使用名称集合恢复选择，避免大量选中文件导致逐项重复遍历。
- 当前目录监听使用容量为 1 的通知队列，并以 150ms 窗口合并变化，减少批量文件操作产生的前后端通知。
- 修复空目录枚举、枚举中途失败被当作成功、1970 年之前文件时间溢出、文件夹定位选中父目录，以及“关闭其他标签页”误关闭保留终端的问题。

开发验证与样本生成见 [开发指南](DEVELOPMENT.md)。

### PowerShell 多终端优化

- `Ctrl+Shift+T` 新建 PowerShell 标签页；标签标题显示启动目录和启动中/已退出状态，右键可复制终端标签。
- 从终端新建或复制终端时沿用其**启动目录**，创建独立会话，不复制已有命令、变量或之后通过 `cd` 改变的目录。
- 每次启动使用独立标识匹配输出与退出事件，同时启动多个终端不会混用输出；后台启动完成不抢夺焦点。
- 启动中关闭标签会清理迟到的会话；应用退出清理终端子进程；退出的终端保留输出供查看。
- Rust 的 PTY 启动、写入、调整大小、关闭在阻塞线程池执行；会话注册表只用于短暂查找，输入保持各终端独立、有序，窗口调整合并并跳过未变化尺寸。
- 修复 UTF-8 跨块中文/emoji 和非法字节后的输出处理；终端提前挂载，事件监听注册完成后再启动 PowerShell，保留 ConPTY 光标握手。

测试命令见 [开发指南](DEVELOPMENT.md)。

### SSH 连接

点击标签栏 **SSH**，或从“设置 → SSH 连接”进入，填写主机/IP、端口、用户名和远程系统。新连接默认开启 **内置 SSH · 凭据记忆与 SFTP**；此前保存的连接继续使用原模式，可在“修改连接”中切换。多个 SSH、PowerShell 与文件标签可同时使用。

#### 内置模式：登录与凭据

- 无需本机安装 OpenSSH Client。填写密码，或指定 **OpenSSH 格式私钥**并在密码框输入私钥口令；不填写私钥时使用密码认证。加密旧 PEM 等格式、MFA/键盘交互、硬件密钥或 SSH Agent 可尝试下述兼容模式，内置模式目前不提供这些认证能力。
- 首次连接展示 SHA-256 主机指纹，通过管理员或可信渠道核对后勾选“我已核对并信任此主机”。确认前不发送密码。信任记录独立于系统 OpenSSH 的 `known_hosts`；指纹变化时重新核对，旧密码不会发送给变化后的主机身份。
- **连接成功后记住密码或口令**默认勾选，可以取消。只有认证和交互终端建立成功才保存；失败的密码不会覆盖原凭据。凭据保存在当前 Windows 用户的凭据管理器，按主机/端口、用户名、主机指纹及私钥路径隔离。连接列表只保存名称、地址、用户、模式和私钥路径，不保存秘密或私钥内容。
- 下次密码框留空即可读取匹配凭据；不会把密码回填或显示出来。“忘记此连接的已保存密码”删除该身份凭据，保留连接配置和主机信任。取消勾选“记住”不自动删除已有凭据。忘记后重新登录需输入密码；凭据不随 EXE 或源码包迁移。
- “同时保存此连接”用于保存可复用的连接配置；与密码记忆分开。内置连接按钮在成功后保存配置，“保存连接”只保存配置。

#### 主机状态

认证成功显示“已连接”，资源查询使用独立通道，不影响终端输入。选择远程系统决定固定的只读查询：

| 模式 | 信息 |
| --- | --- |
| Linux / macOS | 主机名、服务器 IP、系统/内核/架构、用户、运行时间；Linux 内存总量/可用量、根文件系统容量/可用量及平均负载。macOS 等系统按可用命令显示，缺失值显示横线 |
| Windows · 自动获取系统信息 | 调用远端 PowerShell/CIM，显示系统、运行时间、内存总量/可用量与系统盘总量/可用量，需要远端具有对应命令和读取权限 |
| 普通终端（Windows / 网络设备） | 不执行资源查询，适合受限服务器或网络设备 |

登录后自动采集，可点 **刷新资源**更新；这不是连续实时监控。磁盘值是根分区/系统盘容量，不是所有磁盘之和。查询不可用时仍可使用终端，手动刷新会显示具体错误。

#### 远程文件与传输

已连接后点 **远程文件**展开 SFTP 面板。服务器必须启用 SFTP 子系统；文件操作复用当前认证连接，不另存一份密码。Linux 与 Windows 使用同一套 SFTP 协议：首次进入服务端返回的默认目录，路径框使用服务端规范路径（通常为 `/` 分隔），无需把它转换成本地 Windows 路径。

- 双击目录进入，使用上一级、路径输入、刷新导航；显示名称、类型、大小、修改时间。超大目录最多显示前 5000 项或 2 MiB 名称文本，并明确提示截断。
- **上传**选择一个本地普通文件，发送到当前远端目录。**下载**选择一个远端普通文件，再选择本地新文件名；也可双击普通文件下载。传输显示字节数、总量、平均速度、进度与取消按钮，每个连接同时运行一个传输，不同连接互不占用。
- 同名目标存在时明确失败，**不覆盖已有文件**。传输先写独立 `.dalizi-*.part`，成功后发布最终文件。取消或断线会停止复制并尝试清理临时文件；远端已不可达时可能留下临时文件，错误信息给出路径，重新连接核对后可处理。
- 最后完成文件保存阶段会暂时停止接受取消，避免把已经发布的文件误报为取消。网络中断导致结果不确定时，刷新并核对文件，程序不会自动重试或重复传输。
- 当前为单文件传输，不支持目录递归、批量队列、断点续传、远端删除/重命名或链接文件下载。上传完成会刷新列表；这些扩展列入后续规划。

#### 中断、重新登录与兼容模式

SSH 顶部保留 **发送 Ctrl+C / 重新登录 / 修改连接 / 强制断开**，退出后保留终端输出。终端聚焦时 Ctrl+C 用于中断，Ctrl+Shift+C 复制选中文字；重新登录建立独立的新连接，旧输出和旧请求不会覆盖新会话，也不会重放之前的命令。内置模式可使用匹配的已保存凭据重新登录；未保存时通过“修改连接”输入密码。强制断开不保证终止远端后台任务。

关闭 **内置 SSH**后，使用本机 Windows OpenSSH Client + ConPTY。系统未安装客户端时会显示安装指引；主机指纹、密码及密钥口令在终端中交互，不由本程序记住。Linux/macOS 模式沿用登录后的基础信息查询；Windows 或普通模式直接进入终端。兼容模式不提供本版本的资源刷新和 SFTP 面板。两种引擎均使用表单显式配置，目前不读取 `~/.ssh/config` 的主机别名、跳板或额外命令。

内置主机探测超时为 15 秒，连接/认证预算 30 秒，资源查询 10 秒；启用 SSH 保活。关闭标签或退出应用会关闭所属连接并取消传输。SSH 标签没有本地目录工作区，本地 AI 文件助手与目录记忆不会被自动应用到远端路径。

测试方法与范围见 [开发指南](DEVELOPMENT.md#内置-sshsftp-集成回归)。

## 浏览器标签页与访问历史

标签栏的 **Web** 按钮创建原生 WebView2 网页标签，提供地址栏、后退、前进、刷新、主页和网页标题。Windows 上使用 Chromium 内核；多个网页共享应用独立的浏览器配置，Cookie 与网站数据保存在应用本地数据目录的 `browser-profiles/default` 中。

工具栏的历史按钮显示文件夹路径和 URL 访问记录，分别保留最近 100 个目录与 200 个网页地址，在本机保存，重启后仍可查看。点击记录重新打开对应位置。

工具栏的 **拼图** 图标打开扩展管理，直接读取 WebView2 已安装扩展的名称、ID 和真实启用状态。可以启用、停用、确认移除，以及加载包含 `manifest.json` 的单个解压扩展目录。操作作用于共享配置中的所有网页标签；新建标签不会重新安装或重新启用扩展。旧版扩展集合目录设置停止自动加载，已经安装的扩展仍由运行时管理。运行时内置扩展也可能出现在列表中，无法修改时显示原生错误。

扩展能力取决于本机 WebView2 运行时和扩展所用 API。暂不支持商店一键安装、Chrome 账户同步、扩展 action 弹出页与徽标；不能保证所有 Chrome 插件兼容。旧运行时缺少管理接口时会明确提示更新，文件浏览和终端功能仍保留。实现使用 [WebView2 Profile7](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2profile7) 的列表、安装及扩展启停接口。

前端集成测试通过模拟 IPC 验证网页标签、历史、扩展启停失败恢复、安装、确认移除、关闭和切换逻辑。`cargo run --bin browser_smoke` 使用隐藏窗口、独立测试配置和生成的 MV3 扩展，实际验证本机 WebView2 的跨标签扩展状态、停用持久性、启用和移除；不访问真实网站或用户浏览器配置。真实网站、登录与具体第三方扩展仍需单独验收。

### 浏览器设置

入口：**左下角设置 → 浏览器设置**。左侧分类导航对应常规与搜索、网页外观、隐私与数据、网页行为、下载和扩展。没有网页标签时也能保存偏好；新建网页标签沿用保存的配置。

修改后点击 **保存并应用**。关闭或返回设置会放弃尚未保存的修改；**恢复默认**先把默认值填入表单，仍需保存才生效，不删除浏览数据。原生设置失败时会显示错误，不把失败的新配置保存为偏好。

| 分类 | 可设置内容 | 默认与作用范围 |
| --- | --- | --- |
| 常规 | 主页地址 | 默认 Google；主页按钮使用此地址。支持 HTTP、HTTPS、`about:blank`，不允许带账号密码的 URL |
| 常规 | 新建网页标签 | 打开主页 / 空白页，默认主页；不影响文件和终端标签，也不会在应用启动时自动打开网页 |

#### 清除浏览数据

“隐私与数据 → 清除浏览数据”先打开选择窗口，不会立即删除。时间范围为全部时间；勾选项目后点击 **确认清除**：

- **网页访问历史**：清除本应用保存的 URL 列表，保留文件夹访问历史，以及当前标签页的前进/后退记录；没有网页标签时也可清除。
- **上次网页标签快照**：单独清除启动恢复使用的快照，不关闭当前网页。若恢复功能仍开启，之后的导航或标签切换可能再次保存；要停止保存，请关闭“启动时恢复网页标签”。
- **缓存的图片和文件**：调用浏览器配置的数据清理接口，仅清除磁盘缓存。
- **Cookie 与网站数据**：清除 Cookie 和网站 DOM 存储（如 localStorage、IndexedDB），会退出网站登录。需要至少一个已打开的网页标签，作用于所有共享配置的网页。

不会清除 AI 密钥、目录记忆、技能、已下载文件或已安装扩展；也不清除已保存密码和网站权限。清理结果由原生回调确认，失败会显示原因。正在打开的网站可能继续产生新的数据。

#### 保存位置、兼容性与边界

浏览器偏好由主应用本地存储 `df.browserSettings` 保存，网页历史使用 `df.urlHistory`，可选的网页标签快照使用 `df.browserSession`；网页 Cookie、缓存与扩展属于应用本地数据目录的 `browser-profiles/default`。这些配置不与系统 Chrome/Edge 配置共享。设置重启后保留；迁移到另一台机器时，自定义下载目录需要重新核对。

本版未实现浏览器账户同步、完整密码管理器、按站点权限编辑、代理设置、广告过滤规则、无痕标签和网页表单/页面内状态恢复。没有用无效开关模拟这些功能。较旧 WebView2 若缺少所需接口会返回明确错误，建议更新运行时；Windows 10/11 的目标机器仍需分别验收。

需求参考 Chrome 的[主页与启动页](https://support.google.com/chrome/answer/95314)、[默认搜索引擎](https://support.google.com/chrome/answer/95426)，实现依据微软的 [WebView2 Settings](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2settings)、[Settings4 自动填充](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2settings4) 与 [Profile2 数据清理](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2profile2)。仅借鉴常见交互和调用现有内核能力，不引入新的前端或后端框架。

#### 恢复上次网页标签

在“浏览器设置 → 常规与搜索”或“设置 → 收藏与启动”开启 **启动时自动恢复**。网页快照要求“记录网页访问历史”开启；关闭历史记录会清除会话中的网址，关闭自动恢复则仍保留手动恢复入口。详见上方“收藏夹栏与上次工作区”。

- 网页仅保存 HTTP/HTTPS 或 `about:blank` 地址、标题和选中项；相同地址的多个标签保持独立。与文件夹标签合计最多 50 个，超出时保留前面的标签及当前可恢复的活动项。
- 重启后按原顺序恢复文件夹与网页。只有活动网页会立即加载；后台网页选中时才创建原生视图。启动期间已经操作的标签不会被替换，手动恢复时复用已经打开的位置。
- 关闭的网页从后续快照中移除；退出过程中冻结最后的快照，避免销毁回调把它清空。恢复只执行一次，损坏或不支持的快照会忽略；带 URL 用户名/密码或不支持协议的条目不恢复。
- 原生网页创建失败会显示重试入口，也可以修改地址或关闭标签。没有保留网页表单、滚动位置、页面脚本状态、标签内前进/后退栈，也不会恢复或重新执行 PowerShell/SSH 命令。

启动读取目录较慢时，用户新建或切换的标签会保留，不被默认初始化或旧会话选中项覆盖。网页打开过程中再次输入新地址，会话快照优先保存最新目标，旧页面迟到的加载事件不会替换该目标。

快照只保存在本机，不上传服务；地址包含原 URL 的路径与查询参数。清理网页历史和清理标签快照是两个独立选项。浏览器 Cookie 的持久性仍由 WebView2 管理，与是否保存标签快照无关。

#### 下载管理

网页工具栏新增 **下载** 图标；也可通过“浏览器设置 → 下载 → 打开下载管理”进入。设置入口若有草稿会先提示保存；无可用网页标签时显示提示，不会为了打开面板而自动访问网站。有后台网页时可切换到该标签，关闭设置窗口并显示原生下载面板。

下载面板由 WebView2 提供，显示的近期记录、更多历史和可用下载操作由本机运行时决定，不是工作台自建的跨标签任务列表。实现调用微软的 [OpenDefaultDownloadDialog](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2_9) 并等待真实打开状态。内核不支持、标签已关闭或打开失败时显示错误，不伪装成功。

“**在文件标签中打开下载目录**”直接使用本工作台的文件浏览功能，优先使用保存的自定义目录，否则使用系统下载目录；不创建不存在的目录。浏览器新建标签现在也会保留其他标签已经手动调整的缩放，新标签仍使用设置中的默认缩放。

#### 验证方式

测试命令见 [开发指南](DEVELOPMENT.md)。

`tools/ui_smoke.cjs` 使用 Playwright 验证完整设置流程、错误反馈、地址搜索、分类清除与布局，覆盖 1280×800 和 960×560 窗口，截图保存在 `src-tauri/target/ui-smoke/`。该测试需要可用的 Playwright 与 Chromium（可通过 `DALIZI_BROWSER` 指定浏览器程序）。原生 smoke 使用独立浏览器配置和 localhost 测试服务，验证 WebView2 设置与扩展真实行为，不接触日常浏览器数据或外部网站；测试结束会打印保留的临时目录与测试配置路径，便于检查。界面测试中的 IPC 模拟不能替代原生兼容性验证。

## 智能体工作台：模型与本地记忆

模型设置新增“推理参数协议”和“思考强度”。默认通用兼容模式省略推理字段；Chat Completions 下 OpenAI 模式使用 `reasoning_effort`，DeepSeek 模式按 `thinking` 开关和 `reasoning_effort` 发送；Responses 下 OpenAI 模式改为 `reasoning.effort`；Messages 当前只提供服务默认思考设置。API 格式和推理参数协议是不同概念，不支持的组合会被禁用或拒绝。具体模型能否接受某个等级仍以服务商为准，“最高”不会把模型升级为其他型号；不支持时选择服务默认或通用兼容。参考 [DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/) 和 [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。

对话输入区可直接切换思考强度和同一接口且相同 API 格式下保存过的模型。保存最多 12 个模型配置，只保存非密钥字段；API Key 仍仅在本次会话内存中。同接口且同格式切换沿用当前凭据，跨接口需在设置中配置；切换会取消旧请求并使待执行文件计划失效，正在执行文件操作时禁用切换。

显式开启推理时，接收超时为 180 秒、完整响应预算为 240 秒；通用模式、服务默认和关闭思考保留 60 秒 / 90 秒。取消会立即使界面的旧请求失效，但同步 WinHTTP 调用仍需等到响应或超时后释放后台线程。

记忆仍保存在当前本地文件标签目录（本地终端使用该终端的起始目录）的 `.dalizi/agent-memory.json`。移动整个目录连同 `.dalizi` 可携带记忆。记忆管理新增 JSON 导出/导入：导出仅含内容、格式与版本；导入有逐条核对、去重、整批验证及原子保存，新导入项默认停用。不会导出绝对目录、技能或 API Key。记忆作为可编辑上下文使用，学习建议经保存后才成为记忆，不是模型训练或完整会话恢复。SSH 与网页标签没有本地目录记忆。

## Windows 10 / 11 与迁移边界

- 保持 Rust + Tauri 2 + HTML/CSS/JS；现阶段发布 Windows x64 可执行文件。目标为 Windows 10 1809+（ConPTY 终端所需）和 Windows 11；建议在 Windows 10 22H2 与 Windows 11 的目标机器分别验收。不能把本机测试等同于所有 Windows 版本测试。
- 目标电脑需要 Microsoft Edge WebView2 Runtime；较旧的 Runtime 可以浏览网页但未必支持扩展管理。扩展功能做运行时接口检测。PowerShell 使用系统安装，内置 SSH 不需系统客户端，OpenSSH 兼容模式需要系统 OpenSSH Client。目标机器运行程序不需要安装 Rust 或 Node。
- 可执行文件可复制运行，但这还不是所有数据都放在 exe 旁的全量便携模式。模型/界面设置、访问历史、技能配置、索引缓存和浏览器配置属于本机应用数据；目录记忆可随项目或 JSON 备份迁移。浏览器登录凭据、扩展目录与 SSH 密钥不能保证跨机器复制可用。
- 不更改 Windows 的默认文件关联、系统终端或管理员权限。Win32 文件与 ConPTY 适配集中在 Rust 后端，未来替换平台实现时保留上层工作区、权限和配置协议。

## 下一阶段设计方向（尚未实现）

工作台按“目录工作区 → 模型适配 → 上下文/技能/记忆 → 操作计划 → 权限执行 → 结果记录”组织。可以参考 [Deep Agents](https://github.com/langchain-ai/deepagents) 的文件型长期记忆、按需加载技能与上下文压缩设计，保留现有语言框架，不引入其 Python/JavaScript Agent 运行栈。DeepSeek 作为可接入的模型服务处理；应用权限与记忆仍由本地工作台管理。

优先完善：可恢复的本地会话与任务日志、支持进度/取消的多步任务、操作差异预览与失败恢复、模型能力发现和使用量统计、MCP 工具接入及逐工具授权、全量便携数据目录。当前 AI 文件助手仍是受限的文件计划执行器，仅有目录元数据与选中条目上下文，不能据此宣称已经支持任意终端命令执行、网页操控或完整编码智能体。

### 面向集成智能体工作台的建议顺序

以下是基于当前实现的开发建议，尚未作为已完成功能提供；继续保持 Rust + Tauri + 原生前端。

| 顺序 | 方向 | 对当前使用的价值 |
| --- | --- | --- |
| 1 | 目录级 AI 会话恢复与任务日志 | 目前长期记忆与聊天不是同一回事。保存会话、计划、执行结果和错误，重启后能继续查看与追踪；恢复历史不自动执行旧计划 |
| 2 | 文件变更审阅与失败恢复 | 执行前展示目录/文件变化，支持单步确认、进度与取消；对可恢复操作建立备份和回退记录，明确部分完成与不可撤销的边界 |
| 3 | SFTP 批量与远程工作区 | 已有单文件浏览/传输/取消；后续增加双面板、目录递归、队列、断点续传及独立远程 AI 工作区身份 |
| 4 | SSH 配置与诊断 | 分步支持主机别名、跳板、端口转发和连接诊断；配置导入明确展示会执行的连接选项，错误日志导出前过滤凭据 |
| 5 | 工具调用与模型能力适配 | 增加结构化工具调用、逐工具授权、超时/取消和操作记录，再接 MCP；按服务实际能力显示推理等级与上下文限制，提供使用量记录 |
| 6 | 便携与 Windows 兼容验收 | 明确的数据目录与配置迁移版本、启动环境检查，以及 Win10/Win11、中文/长路径、离线/旧 WebView2 的测试矩阵；迁移时不假设浏览器凭据和系统密钥可直接跨机使用 |

建议先做第 1、2 项，形成“对话可恢复、动作可审阅、失败可追踪”的工作流，再扩展批量远程文件与更多工具。[SFTP](https://man.openbsd.org/sftp.1) 适合承接现有 SSH 的文件传输需求；[OpenSSH](https://man.openbsd.org/ssh.1) 的主机配置、跳板和转发能力可以逐步接入，不必更换现有语言框架。
