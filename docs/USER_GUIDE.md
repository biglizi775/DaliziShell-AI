# 使用手册

适用版本：**0.5.1 · 2026-11-03**。[本版发布说明](RELEASE_0.5.1.md) · [历史更新记录](CHANGELOG.md) · [下载最新版](https://github.com/biglizi775/DaliziShell-AI/releases/latest)。

一个用 **Rust + Tauri 2** 打造的 Windows 一体化工作台：文件浏览与预览、快速搜索，以及 PowerShell、SSH 和 Chromium 网页标签，在一个窗口里完成，少切换、少复制。前端保持原生 HTML/CSS/JavaScript，支持中英文。

当前开发版已移除内置 AI 助手。0.5.1 及更早版本写在工作目录 `.dalizi/` 里的聊天档案和记忆、Windows 凭据管理器里以 `DaliziFiles/Model/` 开头的模型密钥，新版既不读取也不删除；不再需要时可以手动删除。

## 最小化到系统托盘

程序运行时会在 Windows 通知区域显示呆梨图标。点击标题栏的最小化按钮，窗口收起到托盘，当前文件标签、PowerShell/SSH 会话及正在执行的任务继续保留。

- 单击托盘图标恢复并聚焦窗口；最大化窗口收起后恢复最大化状态。
- 右键托盘图标可选择“显示窗口”“最小化到托盘”“退出程序”。
- 图标可能位于任务栏右下角的“显示隐藏的图标”（`^`）中，位置由 Windows 管理。
- 标题栏的关闭按钮仍然退出程序。托盘“退出程序”同样执行终端、浏览器与缓存的退出清理。
- 如果系统无法创建托盘图标，程序保留普通任务栏最小化，避免窗口隐藏后无法找回。

## 为什么快

- 目录枚举直接走 Win32（`FindFirstFileExW` + `FIND_FIRST_EX_LARGE_FETCH`），一次调用同时拿到名称/大小/时间/属性，不做逐文件 stat；
- 前端**虚拟化列表**，只渲染可见行及少量缓冲行，降低大目录的 DOM 开销；
- UI 为纯静态 HTML/CSS/JS（WebView2 渲染），由 Rust 后端提供全部系统调用。

## 收藏夹栏与上次工作区

地址栏下方新增收藏夹栏。打开本地文件夹或网页后点击 `☆` 收藏当前位置；已有侧栏固定目录会首次导入，侧栏快速访问继续保留。单击收藏跳转到已有标签，没有打开时创建新标签；Ctrl+单击、中键或右键“在新标签页打开”可另开一份。右键提供编辑、左移、右移和移除；栏末 `•••` 或“设置 → 收藏与启动”可以添加完整路径/网址、修改名称、筛选收藏及隐藏收藏栏。最多 100 项，支持普通盘符、UNC 文件夹、HTTP/HTTPS 与空白网页，不保存网址中的用户名/密码。

“收藏与启动”中的“记住打开的标签”保存最多 50 个标签的顺序和选中位置。在[混合标签恢复预览](PREVIEW_terminal-restore.md)中，文件夹、网页、PowerShell 和 SSH 均可找回。默认启动时自动恢复；曾关闭旧版浏览器恢复的用户沿用关闭偏好。也可关闭自动恢复，通过收藏栏 `↶` 或设置中的“立即恢复上次标签”手动恢复，本次已恢复后不会重复添加，已打开的相同位置会复用。窗口最小化到托盘不算退出，也不会重建标签。

后台网页在选中后才加载；缺失目录、网络不可达或网页失败保留可重试的标签。恢复的 PowerShell 标签显示原启动目录，点击后创建新进程。SSH 标签等你打开登录表单，已保存的连接可重新核对，临时连接需重新输入主机和用户名。会话快照不含命令、输出、凭据或网页表单。

会话与收藏保存于当前 Windows 用户的应用 WebView2 本机存储。关闭“记住打开的标签”清除会话记录并停止保存；关闭“记录网页访问历史”会从当前和上次会话快照中移除网址、停止新增网页快照，文件夹恢复与主动收藏继续保留。浏览器设置中的恢复开关与工作区设置共用；“清除浏览数据 → 上次网页标签快照”只清除网页快照。清除记录不会关闭当前标签，继续导航时可能重新生成记录。

## 标签排序与误关恢复

在[标签目录预览](PREVIEW_file-tab-scope.md)中，从本地 PowerShell 点击标签栏「＋」会打开它的启动目录。从网页或 SSH 点击同一按钮会打开「此电脑」。右键后台标签时，新建文件页或 PowerShell 会使用点中的标签位置。文件夹或右侧对照面板暂时无法打开时会保留目标地址，目录可用后在对应面板重试。

标签较多时，将鼠标停在顶部标签栏上滚动滚轮，即可左右浏览；触控板横向滚动同样有效。标签下方会显示可拖动的滚动条，也可点击轨道跳转。新建文件夹、PowerShell、SSH、网页和误关恢复按钮固定在右侧，不会被挤出窗口。

新建、切换标签或调整窗口大小时自动显示当前标签；后台刷新不会把手动滚动的位置拉回去。拖动标签到左右边缘并停留可连续滚动，松开后完成排序。聚焦标签栏空白处或滚动条后，可用 `← / →`、`PageUp / PageDown`、`Home / End` 浏览标签。

拖动顶部标签可改变顺序，蓝色竖线表示放置位置。当前文件夹、网页或终端保持原会话，不因排序重新加载。也可右键标签选择“向左 / 向右移动标签”，或聚焦标签后按 `Alt+Shift+← / →`。

标签栏末尾 `↶`、右键菜单、“设置 → 快捷操作”中的“恢复刚关闭的标签”可依次恢复本次运行最近关闭的标签，最多保留 20 项。混合标签恢复预览也能在原位置找回待启动的 PowerShell 和 SSH。该记录只在本次运行内保留；恢复后重新打开地址，不恢复网页表单或终端/SSH 进程。关闭网页历史记录或清除上次网页快照时，同时清除可恢复的网页地址。`Ctrl+Shift+T` 仍用于新建 PowerShell。

## 功能

- **全新工作空间界面**：固定侧栏、分层工具栏、常用位置入口、磁盘容量卡片和最近访问目录；默认浅色，可切换深色并记忆偏好
- **文件类型筛选**：全部 / 文件夹 / 图片 / 文档，可与当前目录搜索组合；筛选会清理不可见的选择，避免误操作
- **预览与详情面板**：选择文件后按空格或点预览按钮，优先阅读内容，展开“文件属性”查看完整路径、类型、大小、修改/创建/访问时间及系统属性；支持 PNG/JPEG/GIF/WebP 图片、文本/代码、PDF、Word OOXML 文档和常见表格
  - Rust 只读加载：图片最多 8 MiB，文本最多 64 KiB；支持 UTF-8、UTF-16 BOM，超长文本明确标注截断
  - PDF 最多 32 MiB：内置 [Mozilla PDF.js](https://github.com/mozilla/pdf.js) 6.4.299，支持翻页、指定页码、适合宽度、缩放及加宽阅读。按需绘制单页、限制画布大小；切换文件释放解析与绘图资源。同目录自动刷新不会重置未修改 PDF 的阅读位置。字体、CMap 和解码资源全部打包在本地，不依赖在线预览服务
  - Word `.docx/.docm/.dotx/.dotm` 最多 16 MiB：Rust 在后台解析正文、段落和表格文字，支持中文、UTF-16、严格 OOXML 命名空间和通过包关系指定的正文路径；正文输出最多 256 KiB，截断时提示。预览不还原图片、原始版式、页眉及脚注；不需要安装 Office，不执行宏。ZIP 部件、解压体积和 XML 深度有处理上限
  - 表格 `.xlsx/.xlsm/.xltx/.xltm/.xlsb/.csv/.tsv` 最多 32 MiB：工作表切换、行列标题、横向滚动，每页显示 50 行。Excel 使用 Rust [Calamine](https://docs.rs/calamine/0.36.1/calamine/) 的单元格流式读取，避免按虚假超大尺寸分配整表。预览最多 20 张表、每表前 500 行与 50 列、每单元格 4 KiB、全工作簿文字合计 2 MiB；截断会提示。显示已保存值，不计算公式、不执行宏或外部链接，不还原图表与完整格式。CSV 支持逗号/分号/制表符、引号内换行和 `sep=` 声明；文本支持 UTF-8、带 BOM 的 UTF-16，并对中文 Excel 导出尝试 GB18030
  - 加密 Office、损坏或超过上限的文档给出明确提示，可以点击“打开”交给关联程序处理
  - PDF 支持文件头前的 BOM/短前缀；加密 PDF 可在面板内输入密码，密码仅用于本次本地预览。组件加载失败与文档损坏分别提示
  - 文本按纯文本展示；SVG/HTML、设备、管道、链接及未知重解析类型不做内容预览。已缓存的 Windows Cloud 文件按打开句柄的标签校验；尚未下载的云文件提示先下载，不隐式触发下载。普通长路径/UNC 路径可识别。旧版 `.doc/.xls`、`.ods`、加密 Office 文档仍需关联程序或转换格式；不同失败原因显示具体提示
- **统一设置与快捷操作**：左下角“设置”集中管理主题、预览、显示列、浏览器设置、便携配置、收藏与 SSH 连接；“设置 → 快捷操作”或 `Ctrl+K` 搜索操作、常用目录与打开的标签页，方向键选择、Enter 执行、Esc 关闭
- **键盘浏览**：方向键、Home/End、PageUp/PageDown 联动虚拟列表，Shift 扩展选择；列表/网格偏好自动保存
- **可定制表格列**：默认显示名称 / 修改日期 / 类型 / 大小；右键表头、文件或空白处 →“选择显示列”，可增加创建日期、访问日期、扩展名、属性、完整路径，勾选后“应用”保存。名称始终显示；提供默认显示列与取消按钮。拖动表头改变顺序，拖动边界调整宽度，双击边界自动适配。显示列、列宽和顺序自动保存，窄窗口可水平滚动，表头与文件行保持对齐。
- **文件与文件夹属性**：右键单个项目 →“属性”，查看 9 项基本信息和精确字节数。文件夹另有“大小核验”，显示数值来源和上次完整核验时间。后台返回结果时，已打开的属性窗口会更新。访问日期由文件系统维护，可能延迟更新。
- **统一搜索输入框**：顶栏同一输入框切换“当前目录 / 含子目录 / 全部位置”；当前目录即时筛选，其余模式查询持久化文件名索引，在输入框下方显示结果。`Ctrl+Shift+F` 切到全部位置并聚焦输入框。三种范围支持相同的 Everything 常用语法，输入框旁“?”显示示例。后台索引刷新保留已有结果行、滚动位置和按路径标记的选中项，避免反复清空造成闪烁；输入了新条件后，旧结果暂留到新结果返回，期间不会误打开旧条件的项目。结果可双击打开、在应用内新标签页打开所在文件夹并选中目标，或复制完整路径。隐藏的目标会临时显示，不改变隐藏文件偏好。切换目录或标签页会清除旧关键词和结果，迟到结果不覆盖新范围。
- **外部文件拖入**：从 Windows 资源管理器或桌面拖入文件/文件夹。拖到文件列表空白处代表当前目录，拖到文件夹行代表该子目录；目标会高亮并显示路径。松开后确认“移动到此处”或“复制到此处”，也可取消。同名项目由 Windows 自动重命名，避免覆盖；重复路径合并，原地移动跳过，禁止将文件夹移入或复制到自身及其子目录。操作采用系统文件操作进度窗口，可在其中取消；取消可能留下已完成的部分，界面会提示检查。支持本地与网络共享的真实路径，每次最多 1000 项；不支持网页图片、邮件附件等虚拟对象拖入。浏览器和终端区域不作为本地文件转移目标。

- **浏览器式多标签页**：新建 / 关闭 / 切换 / 中键关闭 / 右键菜单（复制标签页、关闭其他），每个标签页独立历史
- **嵌入式 PowerShell 终端标签页**：标签栏 `> _` 按钮或右键"在终端中打开"，基于 Windows ConPTY + xterm.js，真彩色、交互式（ps1/pwsh 自动选择），起始目录为当前文件夹，随窗口自适应行列
- **SSH 连接标签页**：页头或标签栏“SSH”新建独立连接，可与多个 PowerShell、SSH 和文件标签同时使用。支持主机名、IPv4/IPv6、端口、用户名、私钥路径及保存连接；登录后在终端上方显示连接地址、服务器 IP、系统和运行时间。支持发送 Ctrl+C、强制断开、同标签重新登录并保留输出，也可复制标签开启另一条独立连接。
- 浏览 / 后退 / 前进 / 上一级 / 面包屑（可点击、可直接输入路径，过长自动滚动到末尾显示）
- 文件夹可**固定/取消固定到快速访问**（右键菜单）；侧栏**最近访问**自动记录（最多 8 个，可移除）
- 详情列表视图（名称/修改日期/类型/大小，点击列头排序）+ 网格视图，可切换
- 文件操作：复制 / 剪切 / 粘贴 / 重命名（F2）/ 删除（进回收站）/ 新建文件夹
- 在侧栏打开 **传输任务 → 本地文件**，可查看粘贴、跨面板和外部拖入的逐项结果及实际目标路径。重启后可勾选未执行项恢复，已登记执行但缺少完整回执的项目会提示检查两端。[本地文件任务恢复说明](PREVIEW_local-task-recovery.md)
  - 复制移动删除走系统 `IFileOperation`：原生进度、冲突确认、可撤销
- **持久化目录大小索引**：目录列表直接携带内存索引中的大小，前端在第一次渲染时展示已有数值；刷新不清空旧值。大小和文件名索引分别保存到应用缓存目录的 `folder-sizes-v1.json`、`file-names-v1.json`，启动时优先恢复。距上次完整后台校验不足 10 分钟时，先复用缓存并启用监听，剩余窗口结束后执行一次后台校验；较旧或缺失缓存立即开始后台校验。首次没有缓存的目录仍需扫描，期间显示“计算中…”；不可读目录显示“不可用”，已有数值则保留，UNC 网络路径与符号链接/junction 默认跳过。
  - 默认监听固定磁盘。打开“含子目录”或“全部位置”搜索面板，点击“索引位置”，可以选择本机固定磁盘上的目录。列表留空可暂停后台索引。变更后只在所选范围内维护文件名索引，仍可浏览其他文件夹并用 F5 核验大小。[索引位置说明](PREVIEW_index-locations.md)
  - 当前目录的补算使用单个工作线程与可替换队列，快速切换目录会取消旧任务；后台目录枚举串行执行，降低并发磁盘争抢。前端按帧合并结果，仅更新可见行，按大小排序时合并重新排序。
  - `F5` / 刷新按钮主动重新计算当前列表中的文件夹，等待时仍显示原值。状态栏显示“后台索引中…”提示。
  - 将鼠标停在大小列或打开属性，可查看这个文件夹上次完整扫描的时间。按子目录缓存汇总或读取失败时保留此前的核验时间。旧版缓存缺少时间，会标明“尚无完整核验时间”。即使字节数相同，完整复核也会更新时间。[文件夹大小核验](PREVIEW_size-verification.md)
- 侧栏：**最近访问**（自动记录，最多 8 个）+ 快速访问（桌面/文档/下载/图片/音乐/视频）+ 此电脑（含磁盘容量条）
- 文件夹变更实时监听（`ReadDirectoryChangesW`），外部变化自动刷新
- 本目录即时筛选搜索；显示/隐藏隐藏项
- 双击打开（关联程序）、"打开方式…"、在资源管理器中显示、复制完整路径（含文件名和扩展名）：选中文件/文件夹后右键或工具栏“更多” →“复制完整路径”，也可按 `Ctrl+Shift+C`。多选时每行一个路径，原样保留中文和空格，不添加引号；预览面板复制按钮同样可用。
- 中英文一键切换；偏好（主题/预览面板/语言/视图/排序/上次位置）自动记忆

## 快速搜索

文件压缩请参阅下方“7z / ZIP 压缩”。

搜索默认忽略大小写。当前目录直接筛选已列出的项目，遵循隐藏项和类型筛选偏好。「含子目录」与「全部位置」查询文件名索引，每页显示 200 项。可用上一页、下一页或输入页码后按回车跳转。翻页沿用同一次查询的结果，点击 **刷新结果** 后从最新索引的第一页查看。首次索引尚未完成、目录无权限或达到 100 万项上限时，搜索范围可能不完整。[索引搜索分页说明](PREVIEW_search-pages.md)

| 条件 | 示例与含义 |
| --- | --- |
| 多关键词、词组 | `报告 2026` 同时包含两个词；`"年度 报告"` 包含完整词组 |
| 通配符 | `*.pdf`；`报告?.pdf` 的 `?` 匹配一个字符，`*` 匹配任意数量字符；路径中的 `*`、`?` 不跨目录，`**` 可跨目录 |
| 或、排除、分组 | `*.pdf\|*.docx !草稿`；`<报告 ext:pdf>\|预算`。与 Everything 默认规则一致：`!` 优先于 `\|`，`\|` 优先于空格；使用 `< >` 指定分组 |
| 扩展名与类型 | `ext:pdf;docx`、`file:`、`folder: 项目`；保留 `type:file`、`type:dir` 别名 |
| 路径 | `path:"D:\资料\"` 匹配完整路径；`parent:"D:\资料"` 限定直接父目录；带斜杠的普通路径词也匹配完整路径 |
| 大小 | `size:>10mb`、`size:<=512kb`、`size:1mb..50mb`（范围含两端），单位按 1024 换算；`size:1kb` 匹配 1024–2047 字节，`size:=1kb` 精确匹配 1024 字节 |
| 修改日期 | `dm:today`、`dm:yesterday`、`dm:7days`（包含今天的七个自然日）、`dm:thismonth`、`dm:2026-01-01..2026-12-31`、`dm:>=2026-01-01`；使用本机时区 |

语法实现参考 [Everything 官方搜索语法](https://www.voidtools.com/support/everything/search_syntax/)，属于常用子集。暂不支持 `regex:`、`content:`、拼音、重复文件和额外元数据扩展函数；未知函数、不闭合的引号或不合法范围会显示错误。查询最多 1024 UTF-8 字节、128 项，分组深度最多 16。目录大小条件只使用已有缓存，尚未计算的大小不作为零值；搜索不会同步递归计算目录大小。

搜索采用“预先建立本地文件名索引，输入时查询内存”的方式，后台复用大小扫描收集元数据，不会为每次搜索重新递归磁盘。设计参考 [Everything 的文件名索引思路](https://www.voidtools.com/en-uk/faq/)；本版使用普通权限的目录枚举和变化监听，不包含其 NTFS MFT/USN 服务模式，不承诺相同的首次全盘建库速度。

### 7z / ZIP 压缩

1. 在本地文件标签选中一个或多个文件、文件夹，右键 **压缩…**；工具栏更多菜单也有 **压缩所选项目…**。
2. 在选项窗口填写压缩包名称、保存目录（可点击“浏览…”），选择 7z 或 ZIP，以及“仅打包 / 快速 / 标准 / 更小体积”。切换格式会同步修改文件扩展名。
3. 需要加密时，勾选 **设置解压密码（AES-256）** 并输入两次相同密码。7z 支持中文密码（最多 256 个字符），可勾选 **同时隐藏文件名**，这样查看目录也需要密码。为避免各工具的密码编码差异，加密 ZIP 限最多 99 个英文字母、数字、半角符号或空格；需要中文密码时请选择 7z。ZIP 的目录和文件名保持可见；加密 ZIP 需用支持 AES 的工具（例如 7-Zip）打开。普通 ZIP 不需要密码。
4. 点击 **开始压缩**。界面显示统计、压缩和完成阶段、处理字节数及当前文件。**取消任务** 或 Esc 会请求停止，当前磁盘读写结束后清理未完成文件。成功后可以 **打开所在文件夹**，在新标签中定位压缩包。

原文件始终保留；同名输出拒绝覆盖，也不会修改已有压缩包。输出必须位于所选源文件夹之外。文件夹保持相对目录结构，支持中文名称和空目录。不同来源的同名顶层项目需要分别压缩；符号链接、目录联接和云占位项暂不支持，遇到时任务会明确报错而不是悄悄漏掉。每次最多选择 1000 个顶层项目，展开后最多 100000 项、128 层目录；一次运行一个任务。7z 使用逐文件的非固实 LZMA2 压缩，当前不提供分卷、自解压、解压或更新旧包。

密码不写入配置、历史或日志，不经外部进程命令行传递，启动后输入框会清空。请自行保管密码，忘记后软件不能恢复。正常取消和失败会清理临时包；强制结束进程或断电可能留下输出目录中的 `.dalizi-compress-*.partial` 文件，确认相关任务已退出后可删除。压缩不是文件系统快照；文件正在写入、被独占或压缩前发生变化时可能失败，可停止相关编辑后重试。

压缩能力由 Rust 库内置，用户不必安装 7-Zip。[7-Zip 本身开源](https://www.7-zip.org/)，本功能使用的 `sevenz-rust2` / `lzma-rust2` 采用 Apache-2.0，ZIP 使用 `zip` 库，具体来源与许可见[第三方声明](../THIRD_PARTY_NOTICES.md)。

## 稳定性与性能优化

- 文件复制、移动和删除异步执行，Shell 操作保留独立 STA 线程，等待原生对话框时不阻塞 Tauri 命令线程。
- 部分中止移动时，剪贴板保留尚未执行的源路径。结果不确定的项目可在任务面板核对。重复粘贴同一批会被拦下，执行期间新复制的内容会保留。
- 目录加载、刷新及目录大小查询校验请求版本与所属标签页，避免过期结果覆盖新目录或终端标签页。
- 目录内容未变化时跳过界面重绘；列表和网格按文件复用行节点，滚动、缩放窗口和后台更新不再整块替换列表。
- 刷新结果按返回时的当前选择进行校验，保留等待期间的滚动位置与新选择；重命名输入框在窗口缩放时保留文本、焦点和光标。
- 编辑、右键菜单或列拖动期间的目录变化会延后应用，结束操作后自动跟进；切换目录取消旧编辑，迟到的重命名结果不会改变其他标签。
- 浏览器标签合并重复的显示/尺寸请求，切换时先隐藏旧页面再显示当前页；后台网页保留原视口，创建较慢的网页不会突然盖住当前标签。
- PDF 翻页和缩放先在后台画布绘制，完成后替换可见页，避免绘制过程清空画面；深色主题在初始页面加载时应用，并同步原生窗口底色。
- 当前目录监听使用容量为 1 的通知队列，并以 150ms 窗口合并变化，减少批量文件操作产生的前后端通知。
- 修复空目录枚举、枚举中途失败被当作成功、1970 年之前文件时间溢出、文件夹定位选中父目录，以及“关闭其他标签页”误关闭保留终端的问题。

开发验证与样本生成见 [开发指南](DEVELOPMENT.md)。

### PowerShell 多终端优化

- `Ctrl+Shift+T` 新建 PowerShell 标签页；标签标题显示启动目录和启动中/已退出状态，右键可复制终端标签。
- 从终端新建或复制终端时沿用其**启动目录**，创建独立会话，不复制已有命令、变量或之后通过 `cd` 改变的目录。

- Rust 的 PTY 启动、写入、调整大小、关闭在阻塞线程池执行；会话注册表只用于短暂查找，输入保持各终端独立、有序，窗口调整合并并跳过未变化尺寸。
- 修复 UTF-8 跨块中文/emoji 和非法字节后的输出处理；终端提前挂载，事件监听注册完成后再启动 PowerShell，保留 ConPTY 光标握手。

测试命令见 [开发指南](DEVELOPMENT.md)。

### SSH 连接

点击标签栏 **SSH**，或从“设置 → SSH 连接”进入，填写主机/IP、端口、用户名和远程系统。新连接及未记录引擎选择的旧连接默认开启 **内置 SSH · 凭据记忆与 SFTP**，登录后直接显示服务器目录和上传/下载按钮。明确关闭内置模式的选择会保存，适用于需要 OpenSSH 兼容认证的服务器。多个 SSH、PowerShell 与文件标签可同时使用。

#### 内置模式：登录与凭据

- 无需本机安装 OpenSSH Client。填写密码，或指定 **OpenSSH 格式私钥**并在密码框输入私钥口令；不填写私钥时使用密码认证。加密旧 PEM 等格式、MFA/键盘交互、硬件密钥或 SSH Agent 可尝试下述兼容模式，内置模式目前不提供这些认证能力。
- 首次连接展示 SHA-256 主机指纹，通过管理员或可信渠道核对后勾选“我已核对并信任此主机”。确认前不发送密码。信任记录独立于系统 OpenSSH 的 `known_hosts`；指纹变化时重新核对，旧密码不会发送给变化后的主机身份。
- **连接成功后记住密码或口令**默认勾选，可以取消。主机身份核对和用户认证成功后保存，不要求服务器支持交互终端；失败的密码不会覆盖原凭据。凭据保存在当前 Windows 用户的凭据管理器，按主机/端口、用户名、主机指纹及私钥路径隔离。连接列表只保存名称、地址、用户、模式和私钥路径，不保存秘密或私钥内容。
- 下次密码框留空即可读取匹配凭据；不会把密码回填或显示出来。“忘记此连接的已保存密码”删除该身份凭据，保留连接配置和主机信任。取消勾选“记住”不自动删除已有凭据。忘记后重新登录需输入密码；凭据不随 EXE 或源码包迁移。
- “同时保存此连接”用于保存可复用的连接配置；与密码记忆分开。内置连接按钮在成功后保存配置，“保存连接”只保存配置。

#### 主机状态

认证成功显示“已连接”，资源查询使用独立通道，不影响终端输入。选择远程系统决定固定的只读查询：

| 模式 | 信息 |
| --- | --- |
| Linux / macOS | 主机名、服务器 IP、系统/内核/架构、用户、运行时间；Linux 内存总量/可用量、根文件系统容量/可用量及平均负载。macOS 等系统按可用命令显示，缺失值显示横线 |
| Windows · 自动获取系统信息 | 调用远端 PowerShell/CIM，显示系统、运行时间、内存总量/可用量与系统盘总量/可用量，需要远端具有对应命令和读取权限 |
| 普通终端（Windows / 网络设备） | 不执行资源查询，适合受限服务器或网络设备 |

登录后自动采集，可点 **刷新资源**更新；这不是连续实时监控。磁盘值是根分区/系统盘容量，不是所有磁盘之和。查询不可用时仍可使用终端，手动刷新会显示具体错误。

#### 远程文件与传输

在内置 SSH 标签顶部选择 **双栏传输**，左侧选择本地目录，右侧进入远程目录。选中一侧的项目后，用对应的上传或下载按钮核对清单。也可以分别预览两端的文本，比较同名文件。[双栏操作说明](PREVIEW_paired-files.md)

**内置 SSH** 登录成功后直接进入远程工作区，无需再点击文件入口。默认上方为终端、下方为文件列表，左侧为连接与资源概况；小窗口将概况收拢到顶部。拖动中间分隔条可调整高度，双击恢复默认比例；聚焦分隔条后用方向键调整、Home 恢复。工具栏提供 **分屏 / 文件 / 终端** 三种视图，后台刷新保留手动选择的视图。服务器必须启用 SFTP 子系统；文件操作复用当前认证连接，不另存一份密码。Linux 与 Windows 使用同一套 SFTP 协议：首次进入服务端返回的默认目录，路径框使用服务端规范路径（通常为 `/` 分隔），无需把它转换成本地 Windows 路径。

文件工具栏提供 **根目录 / 主目录 / 上一级 / 刷新**，支持按名称筛选当前已加载目录。筛选后“全选文件”仅选中可见普通文件；清除或改变筛选会清除旧选择。**复制路径**复制所选项目的完整远程路径，未选项目时复制当前目录。Ctrl+L 聚焦远程地址，F5 刷新；目录名称、大小、修改日期有对应表头。应用左下角显示版本号，新工作区版本为 **v0.5.1**。

**交互终端与 SFTP 独立**：服务器拒绝 PTY、禁止 Shell、终端启动超时或在 Shell 中输入 `exit`，只影响交互终端，已连接的目录和上传/下载仍可使用。界面显示终端不可用原因，不把文件连接误报为失败。要结束 SSH 及传输，使用 **强制断开**、关闭该标签或退出软件；要重新建立终端，使用 **重新登录**。资源查询使用另一条只读通道，受限账户可能无法显示系统信息，但不影响 SFTP。

旧连接若显示 **OpenSSH 兼容模式**，当前连接仅有终端通道。点击 **文件管理 / 传输** 会预填同一主机和账户，并选择内置模式；输入密码或使用已有内置凭据，确认连接后在新标签打开文件管理，原终端保持连接。兼容终端输入过的密码不会被读取或复制；需要多因素认证的服务器仍使用兼容终端，内置 SFTP 暂不支持该认证方式。

目录加载失败时，面板显示 SFTP 或权限错误，可点击 **刷新** 重试；SSH 终端连接正常并不代表服务端一定开启 SFTP。目录成功加载前和连接断开后不能发起传输。

- 双击目录进入，使用上一级、路径输入、刷新导航；显示名称、类型、大小、修改时间。超大目录最多显示前 5000 项或 2 MiB 名称文本，并明确提示截断。
- **上传文件**可一次选择多个本地普通文件，**上传文件夹**选择本地目录。**下载**支持 Ctrl 多选、Shift 连选，或“全选文件”（最多前 200 项）；再选择本地保存目录，沿用远端文件名。双击普通文件也可进入下载确认。一次选择 1–200 个项目，开始前展示主机、目标目录和文件清单；本批目标不会随面板导航改变。Windows 不支持的远端文件名、同批冲突名称会在准备阶段提示，需先改名或分批选择。
- 远程文件面板右上角或左下角 **传输任务**、SFTP 进度区“查看任务”以及“设置 → 快捷操作”可打开集中面板。每个连接依次传输，不同连接可同时运行；显示批次成功/失败/取消数、字节数、当前速度和逐文件状态。关闭任务面板后继续传输，完成上传后刷新相同的远端目录并保留仍存在的选择。
- 可在开始前勾选“遇到失败时暂停后续文件”；默认继续其他文件。任务面板提供“完成当前文件后暂停”“继续队列”“取消本批”。取消先移除待处理项目，再等待当前读写、保存或临时文件清理完成，不把取消请求误当作已经停止。
- 本批结束后可点 **重试未成功项…**，重新核对清单后才创建新批次，成功项不会重传。普通重试从文件开头开始；有续传记录时先校验已有内容再继续；原连接已关闭时，可先连接同一主机、账户和私钥身份，再从任务面板重试。启动结果或断线结果未确认的项目，需要先核对目标文件并勾选确认；程序不会自行重连或重放任务。
- 同名目标存在时明确失败，**不覆盖已有文件**。传输先写独立 `.dalizi-*.part`，成功后发布最终文件。明确取消会停止复制并尝试清理临时文件；未启用续传的断线也尝试清理；远端已不可达时可能留下临时文件，错误信息给出路径，重新连接核对后可处理。
- 最后完成文件保存阶段会暂时停止接受取消，避免把已经发布的文件误报为取消。网络中断导致结果不确定时，刷新并核对文件，程序不会自动重试或重复传输。
- 当前运行的传输面板最多保留 50 批。批次确认框默认勾选“在本机保存未开始项”。正常关闭窗口或程序异常退出后，打开 **传输任务 → 恢复未开始项**，可以离线查看主机、指纹、目标目录和剩余文件。登录原主机后，点“核对并加入队列”，逐项审阅，再点“加入传输队列”。查看、启动程序和重新登录均不会自动传输。
- 已启动项的结果可在原连接远程文件面板的 **传输记录** 中核对，记录按主机、账户、主机指纹和远程目录区分。[传输记录说明](PREVIEW_transfer-history.md)主动取消或关闭连接时，当前队列取消余项，仍可在本次运行的任务面板复核重试。可在确认框取消保存清单，仅运行本批。不能绑定本地目录身份时，也可选择这种方式。
- 已经传过部分字节的 SFTP 文件，可在同次运行内断点续传。「传输任务」面板也可以切换到本地复制与移动批次。远端删除、重命名和链接文件下载仍待开发，压缩使用独立的进度窗口。

#### 目录传输与续传（0.5.0）

“上传文件夹”选择一个本地目录；下载时可多选远端目录与文件。准备阶段仅读取清单，确认后创建目录并传输文件，保留空目录。已有目录合并，同名文件失败而不覆盖。展开最多 2000 项、32 层；不跟随符号链接、Windows 目录联接/重解析点。遇到不支持的名称、重名或超限会停止准备，未开始传输。取消不会回滚此前成功的文件或新建空目录。

确认框默认勾选“断线或失败时保留临时文件以便续传”。重新连接相同主机、账户与私钥后，从任务面板手动重试；后端还核对已信任的主机密钥。续传核对源大小/修改时间，并完整读取比较已传入临时文件的字节，随后追加剩余数据，所以恢复前仍可能需要等待和网络读取。源变化或临时数据损坏时拒绝续传，可清理临时文件后重新添加任务。

“取消本批”删除本次活动临时数据；“清理续传临时文件”需连接原主机/账户，只删除程序记录的临时文件。含续传数据的批次不会被“清除已结束记录”直接隐藏。最多保留 128 个续传记录，仅在本次运行中有效；退出前请完成或清理。异常退出可能留下 `.dalizi-*.part`，按错误提示路径核对后手动清理，不能在下次启动自动接续。凭据不写入任务记录。

#### 中断、重新登录与兼容模式

SSH 顶部保留 **发送 Ctrl+C / 重新登录 / 修改连接 / 强制断开**，退出后保留终端输出。终端聚焦时 Ctrl+C 用于中断，Ctrl+Shift+C 复制选中文字；重新登录建立独立的新连接，旧输出和旧请求不会覆盖新会话，也不会重放之前的命令。内置模式可使用匹配的已保存凭据重新登录；未保存时通过“修改连接”输入密码。强制断开不保证终止远端后台任务。

关闭 **内置 SSH**后，使用本机 Windows OpenSSH Client + ConPTY。系统未安装客户端时会显示安装指引；主机指纹、密码及密钥口令在终端中交互，不由本程序记住。Linux/macOS 模式沿用登录后的基础信息查询；Windows 或普通模式直接进入终端。兼容模式不提供本版本的资源刷新和 SFTP 面板。两种引擎均使用表单显式配置，目前不读取 `~/.ssh/config` 的主机别名、跳板或额外命令。

内置主机探测超时为 15 秒，连接/认证预算 30 秒，资源查询 10 秒；交互终端另有通道打开 10 秒及 PTY/Shell 准备 20 秒预算，准备期间显示状态，文件连接不必等待终端。启用 SSH 保活。关闭标签或退出应用会关闭所属连接并取消传输。

测试方法与范围见 [开发指南](DEVELOPMENT.md#内置-sshsftp-集成回归)。

## 浏览器标签页与访问历史

标签栏的 **Web** 按钮创建原生 WebView2 网页标签，提供地址栏、后退、前进、刷新、主页和网页标题。Windows 上使用 Chromium 内核；多个网页共享应用独立的浏览器配置，Cookie 与网站数据保存在应用本地数据目录的 `browser-profiles/default` 中。

工具栏的历史按钮显示文件夹路径和 URL 访问记录，分别保留最近 100 个目录与 200 个网页地址，在本机保存，重启后仍可查看。点击记录重新打开对应位置。

### 网页登录与桌面客户端授权

在 **设置 → 浏览器设置 → 外部应用链接** 中可以检查当前 EXE 的注册情况，以及 Windows 分别为 HTTP 和 HTTPS 选择的处理程序。若提示注册不完整或指向另一个 EXE，点击“注册并打开 Windows 默认应用”。从系统设置返回后面板会重新检查。反馈问题时可点击“复制诊断摘要”，其中包含运行版本、WebView2 版本、注册状态、两种协议是否交给 Dalizi，以及弹窗开关。

- **在网页里点登录**时，授权页会打开为工作台的新标签。它可以先打开空白页再跳转，也可以接收网页提交的表单，并将登录结果传回原页。授权页自行关闭时会回到发起登录的标签。若点登录时提示弹窗被阻止，请开启 **设置 → 浏览器设置 → 网页行为 → 允许网页打开新标签**。
- **客户端给出网址和设备码**时，可以直接把验证网址粘贴到工作台的网页地址栏，按页面提示输入设备码。原客户端负责查询授权结果。
- **让 Windows 把其他客户端打开的网页交给 Dalizi**。先将 EXE 放在固定目录，打开 **设置 → 浏览器设置 → 外部应用链接 → 注册并打开 Windows 默认应用**。在 Windows 11 的默认应用中为 Dalizi Files 选择 HTTP 和 HTTPS。在 Windows 10 可从“按协议指定默认应用”设置。这个系统选择适用于所有按默认浏览器打开的 HTTP/HTTPS 链接。工作台在托盘时会恢复窗口，已退出时会随链接启动。移动 EXE 后请重新注册；要切换回原浏览器，请在 Windows 的默认应用中选择它。
- **返回桌面客户端**。本机回调地址（例如 `http://127.0.0.1:端口/…`）直接在网页标签中导航。对于授权请求通过 `redirect_uri` 声明的部分应用专用回调，Windows 可提示打开对应客户端。客户端强制使用特定浏览器、系统账号代理，或授权服务禁止嵌入浏览器时，按服务提供的登录方式完成授权。Google OAuth 对嵌入式浏览器有明确限制。[Google OAuth 政策](https://developers.google.com/identity/protocols/oauth2/policies)
- 应用自己的访问历史和会话恢复跳过含 `code`、`user_code`、`access_token` 等常用授权参数的网址。Windows 的默认应用选择遵循系统设置。[Windows 默认应用文档](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-default-apps-settings)

工具栏的 **拼图** 图标打开扩展管理，直接读取 WebView2 已安装扩展的名称、ID 和真实启用状态。可以启用、停用、确认移除，以及加载包含 `manifest.json` 的单个解压扩展目录。操作作用于共享配置中的所有网页标签；新建标签不会重新安装或重新启用扩展。旧版扩展集合目录设置停止自动加载，已经安装的扩展仍由运行时管理。运行时内置扩展也可能出现在列表中，无法修改时显示原生错误。

扩展能力取决于本机 WebView2 运行时和扩展所用 API。暂不支持商店一键安装、Chrome 账户同步、扩展 action 弹出页与徽标；不能保证所有 Chrome 插件兼容。旧运行时缺少管理接口时，扩展管理显示当前 WebView2 版本并隐藏加载入口，网页浏览、文件浏览和终端功能仍保留。例如 WebView2 109 可以正常打开网页和登录弹窗，但不能管理扩展。[旧版 WebView2 说明](PREVIEW_browser-runtime.md)实现使用 [WebView2 Profile7](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2profile7) 的列表、安装及扩展启停接口。

前端集成测试通过模拟 IPC 验证网页标签、历史、扩展启停失败恢复、安装、确认移除、关闭和切换逻辑。`cargo run --bin browser_smoke` 使用隐藏窗口、独立测试配置和生成的 MV3 扩展，实际验证本机 WebView2 的跨标签扩展状态、停用持久性、启用和移除；不访问真实网站或用户浏览器配置。真实网站、登录与具体第三方扩展仍需单独验收。

### 浏览器设置

入口：**左下角设置 → 浏览器设置**。左侧分类导航对应常规与搜索、网页外观、隐私与数据、网页行为、下载和扩展。没有网页标签时也能保存偏好；新建网页标签沿用保存的配置。

修改后点击 **保存并应用**。关闭或返回设置会放弃尚未保存的修改；**恢复默认**先把默认值填入表单，仍需保存才生效，不删除浏览数据。原生设置失败时会显示错误，不把失败的新配置保存为偏好。

| 分类 | 可设置内容 | 默认与作用范围 |
| --- | --- | --- |
| 常规 | 主页地址 | 默认 Google；主页按钮使用此地址。支持 HTTP、HTTPS、`about:blank`，不允许带账号密码的 URL |
| 常规 | 新建网页标签 | 打开主页 / 空白页，默认主页；不影响文件和终端标签，也不会在应用启动时自动打开网页 |
| 常规 | 启动时恢复文件夹和网页标签 | 与“收藏与启动”共用设置；最多 50 个文件夹/网页标签，网页保存遵循记录历史开关 |
| 搜索 | 地址栏搜索引擎 | Google / Bing / 百度 / DuckDuckGo，默认 Google；直接输入关键词搜索，完整 URL 或域名直接导航；`localhost:3000` 等回环地址使用 HTTP |
| 外观 | 默认缩放 | 50%–200%，默认 100%；保存时应用到已打开网页，新标签沿用 |
| 外观 | 网页配色 | 跟随系统 / 浅色 / 深色，默认跟随系统；响应网站的配色偏好，不强制重绘所有网站，也不改变工作台主题 |
| 隐私 | 记录网页历史 | 默认开启；关闭后不新增应用内网页访问记录，不删除已有历史，也不是无痕浏览 |
| 隐私 | 表单自动填充 | 默认开启；一般表单信息，不包括密码 |
| 隐私 | 提示保存密码 | 默认关闭；关闭不删除已保存的密码，已有密码仍可能自动填充 |
| 网页行为 | 允许网页打开新标签 | 默认开启；关闭后拦截弹窗及要求新标签打开的链接，不影响手动新建标签 |
| 网页行为 | JavaScript、右键菜单、开发者工具 | 默认开启；网页内容相关变化在刷新或下次导航时生效。禁用 JavaScript 可能影响登录和页面交互 |
| 下载 | 默认下载目录 | 留空使用系统下载目录；自定义时必须填写已存在的绝对目录，不会自动创建目录。已开始的下载不迁移 |
| 下载 | 下载管理与下载目录入口 | 打开 WebView2 原生下载面板，或在文件标签中打开已保存的下载目录；有未保存设置时先提示保存 |
| 扩展 | 扩展管理入口 | 查看、启停、移除、加载解压扩展；需要一个已打开的网页标签，可以使用后台标签对应的共享配置 |

设置应用到所有网页标签，但不修改文件管理器自身的 WebView 设置。创建网页标签时，先应用原生设置再导航到目标网站，避免“禁用脚本”等选项等到首页加载后才生效。后退、前进、刷新使用原生 WebView2 接口。

#### 清除浏览数据

“隐私与数据 → 清除浏览数据”先打开选择窗口，不会立即删除。时间范围为全部时间；勾选项目后点击 **确认清除**：

- **网页访问历史**：清除本应用保存的 URL 列表，保留文件夹访问历史，以及当前标签页的前进/后退记录；没有网页标签时也可清除。
- **上次网页标签快照**：单独清除启动恢复使用的快照，不关闭当前网页。若恢复功能仍开启，之后的导航或标签切换可能再次保存；要停止保存，请关闭“启动时恢复网页标签”。
- **缓存的图片和文件**：调用浏览器配置的数据清理接口，仅清除磁盘缓存。WebView2 109 及更早版本完成这项清理需要一分钟以上，并会拖住随后的清理，因此程序直接提示更新 WebView2；Cookie 与网站数据仍可单独清除。
- **Cookie 与网站数据**：清除 Cookie 和网站 DOM 存储（如 localStorage、IndexedDB），会退出网站登录。需要至少一个已打开的网页标签，作用于所有共享配置的网页。

不会清除已下载文件或已安装扩展；也不清除已保存密码和网站权限。清理结果由原生回调确认，失败会显示原因。正在打开的网站可能继续产生新的数据。

#### 保存位置、兼容性与边界

浏览器偏好由主应用本地存储 `df.browserSettings` 保存，网页历史使用 `df.urlHistory`，可选的网页标签快照使用 `df.browserSession`；网页 Cookie、缓存与扩展属于应用本地数据目录的 `browser-profiles/default`。这些配置不与系统 Chrome/Edge 配置共享。开启下方便携配置后，浏览器偏好、网页收藏与历史可随软件目录迁移，下载目录和登录数据仍按本机管理。

#### 配置与迁移

入口：**设置 → 配置与迁移 → 开启并保存当前配置**。首次使用默认关闭，不会主动在软件目录创建个人数据。

开启后生成 EXE 同级的 `DaliziData/preferences.json`；后续偏好变更自动保存，可查看保存状态、点击“立即保存”或“定位配置文件”。迁移时先退出软件，再复制整个软件文件夹（包括 `DaliziData`），在新电脑运行 EXE，便携设置会在界面与浏览器初始化前读取，无需重新逐项配置。使用新版本 EXE 替换程序时保留该目录。

| 随软件迁移 | 继续由本机管理 |
| --- | --- |
| 主题、语言、列表视图、排序与显示列 | 桌面/下载等系统位置、快速访问、文件夹收藏与历史 |
| 预览偏好 | 上次打开的文件夹/网页标签 |
| 浏览器主页、搜索、缩放、外观与行为偏好 | 下载目录、Cookie、网站登录状态、扩展和缓存 |
| 网页收藏和最多 200 条网页访问历史 | SSH 连接及密码、私钥路径、本地文件索引 |

旧版本保存的模型接口、AI 面板等设置在读取时会被忽略，下次保存配置时自动去掉。网址历史保留原 URL 的查询参数，可能包含私密信息，配置与备份不应随软件公开分发。

同一电脑的文件夹收藏、下载路径和会话不会被外来配置替换；可迁移字段以便携文件为准。两类收藏合计超过 100 项时停止导入并提示整理，不会静默丢弃。关闭便携配置后停止自动保存和启动读取，但保留已有配置文件与本机设置。若要彻底删除便携数据，需要同时删除 `preferences.json` 和 `preferences.previous.json`。

保存采用临时文件与原子替换，并保留上一次版本 `preferences.previous.json`。`preferences.lock` 用于协调写入，退出后自动释放锁，文件本身可以保留。目录不可写、文件损坏、版本不支持或其他实例已修改配置时显示错误，保留原文件与本机设置；自动保存暂停，可修复权限后“立即保存”，或整理配置后重启。恢复备份时先退出所有实例，保留故障文件，将备份复制为 `preferences.json` 后再启动。不要直接复制整个 WebView2 用户数据目录来迁移登录凭据。

本版未实现浏览器账户同步、完整密码管理器、按站点权限编辑、代理设置、广告过滤规则、无痕标签和网页表单/页面内状态恢复。没有用无效开关模拟这些功能。较旧 WebView2 若缺少所需接口会返回明确错误，建议更新运行时；Windows 10/11 的目标机器仍需分别验收。

需求参考 Chrome 的[主页与启动页](https://support.google.com/chrome/answer/95314)、[默认搜索引擎](https://support.google.com/chrome/answer/95426)，实现依据微软的 [WebView2 Settings](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2settings)、[Settings4 自动填充](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2settings4) 与 [Profile2 数据清理](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2profile2)。仅借鉴常见交互和调用现有内核能力，不引入新的前端或后端框架。

#### 恢复上次网页标签

在“浏览器设置 → 常规与搜索”或“设置 → 收藏与启动”开启 **启动时自动恢复**。网页快照要求“记录网页访问历史”开启；关闭历史记录会清除会话中的网址，关闭自动恢复则仍保留手动恢复入口。详见上方“收藏夹栏与上次工作区”。

- 网页仅保存 HTTP/HTTPS 或 `about:blank` 地址、标题和选中项；相同地址的多个标签保持独立。与文件夹标签合计最多 50 个，超出时保留前面的标签及当前可恢复的活动项。
- 重启后按原顺序恢复文件夹与网页。只有活动网页会立即加载；后台网页选中时才创建原生视图。启动期间已经操作的标签不会被替换，手动恢复时复用已经打开的位置。
- 关闭的网页从后续快照中移除；退出过程中冻结最后的快照，避免销毁回调把它清空。恢复只执行一次，损坏或不支持的快照会忽略；带 URL 用户名/密码或不支持协议的条目不恢复。
- 原生网页创建失败会显示重试入口，也可以修改地址或关闭标签。没有保留网页表单、滚动位置、页面脚本状态、标签内前进/后退栈，也不会恢复或重新执行 PowerShell/SSH 命令。

启动读取目录较慢时，用户新建或切换的标签会保留，不被默认初始化或旧会话选中项覆盖。网页打开过程中再次输入新地址，会话快照优先保存最新目标，旧页面迟到的加载事件不会替换该目标。

快照只保存在本机，不上传服务；地址包含原 URL 的路径与查询参数。清理网页历史和清理标签快照是两个独立选项。浏览器 Cookie 的持久性仍由 WebView2 管理，与是否保存标签快照无关。

#### 下载管理

网页工具栏新增 **下载** 图标；也可通过“浏览器设置 → 下载 → 打开下载管理”进入。设置入口若有草稿会先提示保存；无可用网页标签时显示提示，不会为了打开面板而自动访问网站。有后台网页时可切换到该标签，关闭设置窗口并显示原生下载面板。

下载面板由 WebView2 提供，显示的近期记录、更多历史和可用下载操作由本机运行时决定，不是工作台自建的跨标签任务列表。实现调用微软的 [OpenDefaultDownloadDialog](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2_9) 并等待真实打开状态。内核不支持、标签已关闭或打开失败时显示错误，不伪装成功。

“**在文件标签中打开下载目录**”直接使用本工作台的文件浏览功能，优先使用保存的自定义目录，否则使用系统下载目录；不创建不存在的目录。浏览器新建标签现在也会保留其他标签已经手动调整的缩放，新标签仍使用设置中的默认缩放。

## Windows 10 / 11 与迁移边界

- 保持 Rust + Tauri 2 + HTML/CSS/JS；现阶段发布 Windows x64 可执行文件。目标为 Windows 10 1809+（ConPTY 终端所需）和 Windows 11；建议在 Windows 10 22H2 与 Windows 11 的目标机器分别验收。不能把本机测试等同于所有 Windows 版本测试。
- 目标电脑需要 Microsoft Edge WebView2 Runtime；较旧的 Runtime 可以浏览网页但未必支持扩展管理。扩展功能做运行时接口检测。PowerShell 使用系统安装，内置 SSH 不需系统客户端，OpenSSH 兼容模式需要系统 OpenSSH Client。目标机器运行程序不需要安装 Rust 或 Node。
- 在“设置 → 配置与迁移”开启便携配置后，通用偏好、网页收藏与历史保存到 EXE 同级 `DaliziData/preferences.json`；复制整个软件目录即可加载。文件夹路径、索引缓存及浏览器登录数据仍属于本机应用数据。浏览器登录凭据、扩展目录与 SSH 密钥不能保证跨机器复制可用；这还不是完整数据便携模式。
- 不更改 Windows 的默认文件关联、系统终端或管理员权限。Win32 文件与 ConPTY 适配集中在 Rust 后端，未来替换平台实现时保留上层工作区、权限和配置协议。

## 本地双面板（0.5.0）

在文件夹标签点击“**双面板**”打开右侧文件对照面板。它具有独立路径输入、返回/上级、刷新、名称筛选及 Ctrl/Shift 多选；每个标签各自保留本次运行的状态，切换标签不会串目录。列表按可见区域渲染。

“选中项 →”把左侧选择交给右侧目录，“← 选中项”反向处理；确认框显示固定来源与目标，再选择复制或移动。同名文件由系统自动重命名。外部真实文件也可拖入对照面板。操作完成刷新两侧，右侧目录被外部修改时可点击刷新或按 F5。

点击右侧“**设为工作目录**”会交换两侧位置，并把右侧选择带到主面板。双面板展开时暂时隐藏文件预览；关闭后恢复原预览偏好。双面板状态暂不跨应用重启恢复，终端与网页不显示此面板。

## Studio 界面风格

在“设置 → 界面与浏览 → 界面风格”选择“概念片风格 / Studio”或“经典 / Classic”。Studio 是默认风格，提供暖白、墨黑、金色与低饱和绿色的视觉；经典保留之前的蓝色界面。界面风格与“外观主题”的浅色/深色选项相互独立，切换风格不会关闭标签、改变文件选择或中断会话。偏好即时保存，开启便携配置后随通用偏好一同导出和恢复。
