# 重启后恢复 SFTP 批次

打开 **传输任务 → 恢复未开始项**。即使 SSH 已断开，也可以查看本机保存的主机、账户、指纹、传输方向、目标目录和剩余文件。登录原主机后，选中批次，点击 **核对并加入队列**，再确认文件和目标目录。

例如，一批三个下载任务在第一个文件传输时意外退出。正常关闭窗口时，已暂停队列的未开始项也会保留。重启后，第一个文件的结果在原目录的 **工作区历史 → SFTP** 中核对。恢复面板列出后两个文件。窗口中的当前文件夹或其他已登录主机不会改变这两个项目的目的地。主机指纹已更换或原本地目录已被同名目录替代时，须重新选择并审阅文件。

新批次默认在本机应用数据目录的 `sftp-batches` 中保存审阅过的路径与设置。可以在入队前取消勾选，也可以在恢复面板移除已保存的清单。删除清单会保留两端文件和已有传输历史。已取消或全部启动的清单会自动退出恢复列表。旧预览版的内存队列无法补建。

恢复清单不含密码、私钥路径或字节续传令牌。程序异常退出时，正在传输的文件可能留下临时文件。请核对两端文件，再决定如何处理这一项。本次运行中断线后继续传输部分字节的操作，仍从原来的传输任务面板开始。
