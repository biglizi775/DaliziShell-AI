# 开发预览：按目录清理文件任务

此功能在 RC6 之后的开发预览中提供。解压到新目录运行；同一 Windows 账户中的预览版和 RC6 共用本机任务索引。试用删除功能时请使用测试账户和临时项目。退回旧程序不会恢复已确认删除的记录。

1. 本地：进入目标目录，打开「AI 对话 → 文件任务」。内置 SSH：在相应服务器的 SFTP 面板打开「在此远程目录提问」。
2. 在「任务记录」中点「清理此目录的任务记录…」。会列出目标、已结束的记录数、未提交的快照预览数、旧索引记录数和保留的记录数。SSH 确认框还显示服务器指纹。「查看所有目录」中没有批量清理按钮。
3. 核对后选择「确认清理」。取消不会移除任何数据。如果清单或目录身份变化，先前的确认不再有效，须重新查看清单。

清理的是当前用户的本机任务记录、绑定这一目标的预览、旧版本索引中的相应记录，以及这些任务的 SDK 临时目录。已结束任务的旧副本也会一并清除。运行、待审阅、正在写入或撤销的任务会保留；只有旧索引知道且状态未结束的记录也会保留。

项目文件、目录聊天与记忆、项目里的编辑备份和服务器内容不受影响。清理已写入任务会移除该任务卡上的撤销按钮，确认框会单独提醒。文件被占用导致清理中断时，先解除占用再重新核对；已经清掉的临时目录或旧索引副本不会自动恢复。
