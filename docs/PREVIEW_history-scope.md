# 按目录查看任务记录

在「文件任务 → 任务记录」勾选「查看所有目录」，每条任务的标题下方会显示保存回答的目录。网页引用显示你在提交前选定的本地项目。SSH 任务显示账户、服务器、端口和远程路径。

例如，A 有一个尚在处理的问题，B 是移动硬盘上的固定项目。在 B 打开全部任务时可以找到 A。取消勾选的同时，A 的记录和操作按钮会从列表移除。如果 B 暂时不可读，列表会显示读取错误。接回硬盘并点击「重新读取任务记录」，即可查看 B。只有成功读到空列表时，界面才会显示「暂无任务记录」。

A 完成后，回答仍在 A。要从 B 查看它，可再勾选「查看所有目录」并展开 A 的那条记录。如果在打开旧记录的操作确认框后列表范围发生变化，需要在当前列表重新选中记录。
