# 更新记录

## 0.4.0 — 记忆整理、收藏夹与工作区恢复

- 新增聊天上下文统计、估算 Token、自动/手动摘要与摘要查看；复用当前模型 API，保留近期原文，支持取消与失败回退。摘要不作为持久偏好或文件执行授权。
- 目录记忆显示条数、启用数、正文大小与重复项；对话前可自动精确去重，先写完整备份，再原子更新当前目录记忆。聊天压缩与长期记忆自动整理可分别关闭。
- 新增文件夹和网页共用收藏夹栏，支持当前位置收藏、名称编辑、筛选、右键排序、新标签打开及栏显隐；首次导入旧固定目录。
- 统一保存并恢复最多 50 个文件夹/网页标签及顺序、选中位置；支持自动与手动恢复、后台网页延迟加载、复用已打开位置。保留浏览器历史关闭与清理偏好的边界，不自动恢复终端、SSH 或 AI 对话。

验证：213 项前端测试、94 项 Rust 测试通过（1 项旧 OpenSSH 集成测试默认跳过）；完整 UI 回归及工作台专项检查通过。Windows 发布版使用本机 HTTP 样本验证三种 API 的自动摘要、后续复用、目录记忆去重/备份/导入，并验证真实进程退出重启后的收藏和混合标签恢复。未调用真实云模型，Token 数仍为估算；不同 Win10/Win11 与 WebView2 组合需分别验收。

## 0.3.1 — 系统托盘

- 运行时显示原生托盘图标；标题栏最小化后收起到通知区域，保持文件标签、终端会话及后台任务。
- 单击图标恢复并聚焦窗口；右键菜单提供显示窗口、最小化到托盘和退出程序。最大化状态随窗口恢复。
- 托盘创建失败时保留普通任务栏最小化；标题栏关闭和托盘退出仍执行应用退出清理。

验证：91 项 Rust 测试通过（1 项旧 OpenSSH 集成测试默认跳过）；原生托盘检查覆盖通知区图标注册、连续最小化/恢复、最大化恢复、窗口未重建、无托盘时的回退和正常退出事件。发布版实际点击标题栏最小化后，窗口收起且进程保留；托盘菜单实际点击仍需在目标桌面验收。

## 0.3.0 — AI API 格式与测试

- API 格式单独选择 OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages，分别处理路径、认证、系统提示、历史及文本响应。原配置保留 Chat Completions。
- 新增“测试 API”：使用当前表单发送固定短消息，展示耗时、模型、最终地址与分类错误；不保存配置、不携带工作区上下文。修改/关闭/取消后旧结果不覆盖当前状态。
- API 格式与推理参数协议分离；模型快捷切换限制在同地址、同格式内。响应截断、错误 JSON、空响应和仅推理/工具内容不视为成功。
- 保持现有文件计划校验与权限流程；三种协议暂为非流式文本，Messages 使用服务默认思考和 4096 输出 token 上限。
- 修复保存推理模型后重启时的配置初始化顺序。

验证：199 项前端测试、91 项 Rust 测试通过（1 项旧 OpenSSH 集成测试默认跳过）；本机 HTTP 测试覆盖三种协议，发布版真实应用完成 API 测试与对话、认证头、历史、HTTP 401、错误内容及密钥不落盘验证。未使用真实云服务密钥测试。

## 0.2.1 — 复制完整路径

- 文件/文件夹右键菜单及工具栏“更多”提供“复制完整路径”，包含文件名和扩展名；也可使用 Ctrl+Shift+C。
- 多选时按每行一个路径复制，保留中文、空格和网络共享路径；预览面板复制入口同步使用成功/失败提示。
- 普通 Ctrl+C 保留文件复制，输入框与终端保持各自快捷键行为。

验证：194 项前端测试通过；复制路径专项 UI 检查覆盖右键、多选、中文/空格/特殊字符、盘符根目录、UNC 网络路径、快捷键、输入框隔离与剪贴板失败提示。

## 0.2.0 — SSH 与远程文件

- 新建连接默认使用 Rust 内置 SSH，已有 OpenSSH 连接配置继续保留；可按连接切换引擎。
- 首次连接核对主机指纹；认证及交互终端成功后可将密码/私钥口令记入 Windows 凭据管理器。支持忘记凭据、保存后重连，主机指纹变化时不发送旧密码。
- Linux/Windows 资源信息显示内存和根文件系统/系统盘总量、可用量，提供手动刷新；普通终端模式不执行采集。
- SSH 面板增加 SFTP 目录浏览、单文件上传/下载、进度、平均速度和取消，复用当前认证连接。流式传输，同名目标不覆盖；失败/取消尽量清理临时文件。
- 保留 Ctrl+C、修改连接、同标签重新登录和终端历史；迟到事件不会污染新会话。

验证：194 项前端测试、85 项 Rust 测试通过；1 项需 OpenSSH/Git Bash 的旧集成测试默认跳过。完整 UI 回归与 release EXE 的本机 SSH/SFTP 集成回归通过，覆盖密码/私钥、指纹变化、传输冲突/取消和最小窗口。Windows CIM 查询在本机验证；远端 Linux/Windows 资源响应使用协议样本，不代表所有真实服务器环境已验证。

边界：内置认证目前支持密码或显式私钥；加密私钥使用 OpenSSH 格式，其他格式及 MFA 等可尝试兼容模式。SFTP 服务器需要启用子系统，目前不支持递归目录、批量队列、覆盖或断点续传。凭据与主机信任绑定当前 Windows 用户，不随 EXE 迁移；远程文件尚未接入 AI。
