# 重启后恢复本地文件任务

双面板传输、从资源管理器拖入和剪切粘贴共用同一份本机任务记录。在侧栏选择 **传输任务 → 本地文件**，或在命令面板搜索 **本地文件任务**。程序重新启动后可以先查看原批次，再决定是否继续。

| 重启后显示 | 如何处理 |
| --- | --- |
| 已完成 | 查看 Windows 回报的实际目标路径，包括同名时生成的新名称。 |
| 未开始、未执行 | 点击 **重试未执行项**，勾选要继续的项目，核对源和原目标目录后确认。 |
| 请核对源和目标 | 项目已交给 Windows 或已为交付登记，记录中缺少完整回执。核对两端实际内容后，可在文件夹中重新选择。 |
| 无法验证原路径身份 | 文件系统未提供可重用的身份标识。请在文件夹中重新选择。 |

每次重试会生成一个新批次。原批次保留每一项的重试批次号。即使在确认重试后立即强制关闭，重启后也只有一个批次可以继续该项。

恢复时会核对 Windows 卷和文件标识。普通源文件还会核对大小和最后写入时间；目录核对目录本身的身份，内部文件按实际执行时的内容处理。若有人在同一路径换了文件或目标目录，该项会留在审阅框。可以取消勾选它，先处理其他项目。网络共享暂时离线时，可待连接恢复后再核对。

记录保存在当前 Windows 用户的工作台 WebView2 配置中，包含路径、状态和回执，不保存文件内容。删除工作台配置会清除这些记录。自动保留最近 40 个已处理完的批次；仍可恢复或需要核对的批次保留到手动移除。**清除已结束记录** 清理已处理完的批次。要单独放弃某个待恢复记录，选中它，点击 **移除此记录** 并确认。清理记录只影响任务面板。
