# 选择参与索引的文件夹

后续预览还可在“排除目录”中指定跳过的子树。[索引排除与 Windows 环境检查](PREVIEW_windows-compat.md)

在工作区顶部，将搜索范围切换到 **含子目录** 或 **全部位置**，点击 **索引位置**。

1. 选择 **指定文件夹**。用 **选择文件夹…** 添加目录，也可以每行粘贴一个本机固定磁盘上的绝对路径。
2. 点击 **应用**。后台开始扫描这些目录及其子目录。重复路径和已经包含在父目录中的路径会合并。
3. 查看搜索面板底部的索引进度和位置数。新加入的目录会随着扫描逐步出现，移除目录的结果会立即退出索引，之前打开的搜索页会失效。

指定列表留空再应用，可暂停后台索引。选择 **所有固定磁盘** 并应用，可恢复默认范围。设置保存在本机的应用配置目录，重启后仍然有效。添加无效路径时，对话框会说明原因并保留上次成功保存的设置。

索引范围影响递归扫描、磁盘监听及“含子目录”和“全部位置”搜索。当前文件夹内的即时筛选仍可使用。范围外也能打开目录或按 F5 计算文件夹大小，其内容不会因此加入全局搜索。

被移走或暂时离线的位置仍保留在选择列表中。程序会定期核对指定目录，目录重新出现后会重新监听并扫描。搜索状态会标出未能监听的位置，也可点击 **重新校验索引** 主动重试。网络位置和经过重解析点的目录不能选作索引根。
