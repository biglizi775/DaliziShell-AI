# 开发预览：固定项目切换标签后的文件操作

在本地目录 A 打开「AI 对话 → 项目」并固定 A。启用「项目工具」，选「自动执行」，发起文件操作后切到目录 B、网页或 SSH。聊天目标依旧是 A，权限会变为「确认后执行」。即使回到 A 才收到回答，也不会自动写文件。

要执行这份计划，请展开原对话中的计划，核对路径、勾选确认并点击「确认执行」。修改已有文档仍须审阅差异。要为后续请求重新启用自动执行，请回到 A 的本地目录后手动选择；普通刷新不影响已选权限。

此版保留[索引缓存修复](PREVIEW_index-cache.md)和[按目录清理文件任务](PREVIEW_workspace-history.md)。完整解压到新目录，保留内层组件 ZIP。正式验收仍使用[冻结的 M5 候选包](HARNESS_M5.md)。
