# Dalizi Files v0.5.0

把文件浏览、AI 对话和远程传输放进同一个窗口。这次发布合并了 v0.4.0 之后的本地开发改进。

## 文件处理

- 本地双面板：独立路径与选择、虚拟列表、跨面板复制/移动、切换工作目录。AI 与记忆明确跟随左侧工作目录。
- 搜索支持 Everything 常用条件组合；结果可在应用内新标签定位；外部文件拖入后可选择移动或复制。
- 新建 7z/ZIP 压缩包，支持 AES-256 密码、7z 文件名加密、压缩级别、进度与取消。

## SSH 与传输

- SFTP 批量上传/下载、集中任务面板、暂停后续文件、取消与仅重试未成功项。
- 文件夹递归传输保留目录层次和空目录，已有目录可合并，同名文件不覆盖。
- 断线后可在重新登录后手动续传。续传绑定主机身份和账户，检查源信息，并完整核对已传字节；损坏或变化时拒绝拼接。

## 工作区与稳定性

- 目录级聊天档案、可选自动保存、历史恢复与 Markdown 导出；恢复不重放旧操作。
- 标签排序与恢复最近关闭的文件夹/网页；可选 EXE 同级 DaliziData 保存通用配置、网页收藏和历史。
- 减少目录刷新、窗口缩放、浏览器布局与 PDF 翻页的重复绘制，保留选择、滚动和编辑状态。

## 使用与升级

下载 `dalizi-files-0.5.0-windows-x64.zip`，完整解压后运行 `DaliziFiles.exe`。目标环境为 Windows 10 1809+ / Windows 11 x64，需要 Microsoft Edge WebView2 Runtime。发行包未签名。内置 SSH 无需系统 OpenSSH；OpenSSH 兼容模式需要系统客户端。

升级前退出旧程序。保留原有 `DaliziData/` 配置目录，以及项目目录中的 `.dalizi/` 记忆与聊天档案；将新版文件解压到原软件目录。发行包不包含个人配置、浏览器资料、密码或 API Key。浏览器登录及系统 SSH 凭据仍与当前电脑/Windows 用户关联。

## 验证与边界

- 256 项前端测试、117 项 Rust 测试通过；1 项既有 OpenSSH 环境测试默认跳过。
- UI 回归覆盖双面板、传输队列、聊天档案、标签管理与刷新稳定性。
- 真实 EXE 在生成的回环 SSH/SFTP 服务验证了目录传输、空目录、上传/下载续传、取消清理、损坏临时数据拒绝与同名保护。
- 续传记录仅保留在本次程序运行中，最多 128 条；退出前请完成或清理临时数据。不自动重新登录、重放任务或跨重启续传。
- 一次最多选择 200 个 SFTP 项目，递归展开最多 2000 项、32 层；不跟随链接或目录联接。取消不回滚已成功文件或新建空目录。
- 双面板目前用于本地文件；远程文件仍在 SSH 面板管理，远端 AI 操作未接入。Office 预览以内容为主，浏览器仍受 WebView2 扩展 API 支持范围限制。
- 原生验证在当前开发机与测试服务完成，不代表所有 Windows 10/11、WebView2 和第三方 SFTP 服务组合均已验证。
