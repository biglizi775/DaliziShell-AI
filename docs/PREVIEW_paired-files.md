# 在 SSH 标签中对照本地与远程目录

使用内置 SSH 登录，在工作区顶部选择 **双栏传输**。右侧显示这条连接的远程目录。左侧点击 **选择目录** 或输入本地绝对路径并回车。每个 SSH 标签单独保存这两个目录和选择。重新登录后，可重新选择本地目录。

- **上传**。在左侧选择本地文件或目录，点击 **上传选中项 →**。审阅框显示主机、固定的远程目标和展开后的项目。确认后使用原批量队列传输。
- **下载**。先定位左侧保存目录，再选择右侧项目，点击 **← 下载到本地**。只在地址栏输入新路径时，按回车完成导航后才能提交。取消审阅会保留原文件。
- **核对文本**。在任一侧选中一个普通文件，点击该侧 **预览文本**。每侧最多读取前 64 KiB，两侧可同时预览同名文件。导航、改选或关闭预览会撤销该侧的显示。文本留在当前窗口。
- **使用 Agent**。从左侧 **文件标签 ↗** 可打开独立的本地工作目录。远程只读问答位于右侧 **更多 → 在此远程目录提问**，按原账户、主机指纹和远程目录审阅所选内容。点击左侧文件只改变传输和预览的选择。

两栏均支持按名称筛选、Ctrl 多选和 Shift 连选。本地列表每页 100 项，每批最多选择 200 项。递归、同名保护和异常退出后的恢复沿用原传输队列。服务器只提供 SFTP 时，双栏仍可使用。
