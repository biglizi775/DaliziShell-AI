# 重启后找回文件夹、网页、PowerShell 和 SSH 标签

在「设置 → 收藏与启动」中启用「记住打开的标签」。如果同时启用「启动时自动恢复」，下次打开程序会回到上次选中的标签。关闭自动恢复后，可以用收藏夹栏的 ↶ 手动找回上次的标签。最多保存 50 个。

- 文件夹回到之前的位置。后台网页在选中时加载，关闭网页历史记录后，网址会从会话快照中移除。
- PowerShell 显示原来的启动目录。点击「启动 PowerShell」在同一个标签打开新进程。之前在终端内执行的 `cd`、命令、输出和环境变量不会重放。
- 已保存的 SSH 连接按配置编号找回。点击「打开 SSH 登录」后可核对当前主机、端口和用户名，再点击「连接」。密码框留空时沿用现有凭据规则。临时连接和已删除的配置显示空白登录表单。
- 误关终端时，点击**标签栏**右侧的 ↶ 或右键「恢复刚关闭的标签」，可以在原位置找回待启动的标签。最近关闭记录最多 20 项，退出时清空。`Ctrl+Shift+T` 用于新建 PowerShell。

会话快照只记终端类型、PowerShell 启动目录或已保存的 SSH 配置编号。认证信息由原有登录流程处理。恢复标签不会向服务器发起探测，也不会重启 SFTP 传输或提交 Agent 任务。

如果启动目录已移动，标签会显示缺失的路径。目录恢复可用后，可在原标签重试。内置 SSH 登录时输错密码，表单会显示错误、保留主机信息并清空密码框，可以直接重新输入。
