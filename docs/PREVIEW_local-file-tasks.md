# 本地复制与移动任务

在文件标签中粘贴、在双面板中传输，或从资源管理器拖入文件后，打开侧栏的 **传输任务 → 本地文件**。也可以在命令面板搜索 **本地文件任务**。

每批最多选 1000 项。批次确认后绑定原目标目录，切换标签或关闭面板都可以继续工作。每个顶层文件或目录由 Windows 单独处理。重名时保留两份，完成项会列出 Windows 回报的实际目标路径。重复选择、已被选中目录包含的项目和原地移动会标记为跳过。

- 点击 **停止后续项目**，仍在排队的项目会显示 **未开始**。正在处理的项目可通过 Windows 文件操作进度窗口取消。
- 点击 **重试未执行项**，可核对原目标、操作类型及尚未执行的源路径。若某个源文件仍不可用，可取消勾选它，先处理其他文件。重试会新建批次，原记录保留每项的重试批次号。
- 如果 Windows 中途取消、只完成了部分目录或没有返回完整回执，该项显示 **请核对源和目标**。请打开源和目标查看内容，再决定是否重新选择。后续排队项可以单独重试。
- 剪切后粘贴，剪贴板仅保留可安全重试的原路径。执行时新复制或剪切的内容会保留。

这一版预览保留本次运行最近 40 个结束批次。后续版本已支持[重启后恢复本地文件任务](PREVIEW_local-task-recovery.md)。压缩、删除仍使用各自的操作入口。
