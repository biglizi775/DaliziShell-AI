# Windows 环境检查与索引排除

当前压缩包附带 `Check-Windows.ps1`。如果桌面打不开，可在解压目录运行该脚本查看操作系统构建、架构和 WebView2。内嵌终端从 Windows 实际安装目录查找 PowerShell，并检查系统 ConPTY 接口。文件列表、便携设置及双面板导航兼容缺少部分较新 JavaScript 方法的运行时。

在“含子目录”或“全部位置”搜索面板打开 **索引位置 → 排除目录**。填写固定盘上的绝对路径，每行一个，或者使用选择按钮。排除项对“所有固定磁盘”和“指定文件夹”都生效。可以提前填写尚未创建的目录。

保存后，索引搜索会移除排除目录本身及其内容。监听器会忽略这些目录内的变化，后台扫描也会跳过整棵子树。相似名称的同级目录仍然参与索引。

文件列表始终可以显示真实的目录。完整大小受排除项影响时会保留上次核验的数值；尚未取得完整大小时显示“F5 核验”。回到列表按 **F5** 会计入排除目录的实际字节，索引搜索仍然遵守排除设置。

排除设置保存在本机。旧版配置升级后默认没有排除项。需要退回早期“索引位置”预览时，可先在本版清空排除项再保存，让旧版读取同一份配置。
