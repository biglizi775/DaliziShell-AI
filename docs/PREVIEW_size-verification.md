# 查看文件夹大小的核验时间

在详细列表中，将指针停在文件夹的“大小”列，或右键打开“属性”，查看“大小核验”。回到列表后按 **F5**，可以重新扫描当前列表里的本地文件夹。列表和已打开的属性会接收后台结果。大小按普通文件的逻辑字节数计算，跳过重解析点。

| 显示 | 含义 |
| --- | --- |
| 本次运行已完整核验 | 已逐层读取此目录和可扫描的子目录。数值相同时，完成时间也会更新。 |
| 上次运行的缓存 | 本次启动从磁盘恢复了大小。显示的时间是当时对这个文件夹最后一次完整扫描的时间。 |
| 按子目录缓存汇总 | 监听到变化后重新汇总，其中使用了已缓存的子目录大小。时间仍指上次完整核验。 |
| 未能完整读取，保留上次数值 | 一个或多个目录读取失败。文件夹保留之前的大小和完整核验时间。恢复访问权限后可按 F5 重试。 |
| 尚无完整核验时间 | 旧版缓存只有字节数，或当前大小仅来自增量汇总。完整扫描后才会出现时间。 |

首次读取失败且没有缓存时，大小显示“不可用”。成功读完的空目录显示零字节。UNC 网络目录和重解析点保持跳过扫描。
