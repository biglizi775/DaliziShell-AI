# 重启后核对本地文件操作

打开上次运行文件计划的本地目录，在 Agent 面板选择「文件操作记录」。每条记录显示计划中的目标和已完成的步骤数量。打开详情可以查看每一步的路径、状态、耗时和失败原因。

例如，助手先创建文档，再移动文件。如果移动过程中程序退出，记录会保留创建文档的结果。移动步骤显示「结果待核对」时，请同时查看源路径和目标路径，再决定是否生成新的计划。打开历史不会触发执行。

多步计划运行期间可以选择「停止后续步骤」。当前文件操作返回后，程序会跳过剩余步骤。临时对话也会写入这份记录，日志保存在当前本地工作目录的 `.dalizi/tasks`，仅包含计划与执行元数据。

每个目录最多保存 128 条文件计划。可以在核对后移除单条记录，实际文件继续保留。本预览覆盖从本地 Agent 对话提交的文件计划。单独保存回复、撤销修改、Harness 任务和 SFTP 传输仍使用各自的入口。
