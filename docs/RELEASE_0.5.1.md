# Dalizi Files v0.5.1

2026-11-03 · Windows x64 · SSH 工作区与标签栏修复

SSH 登录后直接显示终端、服务器目录和资源概况；大量标签也能通过滚轮或滚动条访问。本版继续使用 Rust + Tauri 2 + 原生 HTML/CSS/JavaScript。

## SSH 工作区

- 内置 SSH 认证成功后自动加载远程目录，上方终端、下方文件列表、左侧主机信息；小窗口使用紧凑布局。
- 拖动分隔条调整高度，双击恢复默认；工具栏提供分屏、文件、终端三种视图以及 Ctrl+C、重连、断开。
- 文件面板提供主目录/根目录跳转、当前目录名称筛选、名称/大小/修改日期表头、复制远程路径，直接使用上传、下载和传输任务。
- 后台资源刷新保留输入焦点；筛选后全选仅选中可见普通文件。沿用批量/目录传输、取消、重试与同次运行内续传。

## 修复与交互

- 修复 SSH 通道窗口调整消息被误判为拒绝交互终端或 SFTP。
- 交互终端独立准备，PTY/Shell 被拒绝、超时或退出不会关闭 SFTP；准备预算延长至 20 秒，期间文件管理仍可使用。
- 补查连接状态并过滤迟到事件，防止登录成功后文件面板没有打开或状态倒退。
- 标签栏支持滚轮、可拖动滚动条、活动标签自动显示及拖动到边缘滚动；新建按钮固定在右侧。
- 左下角显示 v0.5.1，帮助确认当前运行版本。首页、使用手册与开发规划同步，并新增历史版本快速导航。

## 下载与升级

下载附件 `dalizi-files-0.5.1-windows-x64.zip`，完整解压后运行 `DaliziFiles.exe`。附带许可证、使用说明、历史更新记录、构建信息与 SHA-256 校验；GitHub 自动生成的 Source code 用于开发，不能直接运行。

需要 Windows 10 1809+ / Windows 11 x64 与 Microsoft Edge WebView2 Runtime，无需安装 Rust、Node.js 或 Python。发行包尚未签名。

升级前退出旧程序，保留原有 `DaliziData/` 配置，以及工作目录中的 `.dalizi/` 记忆与聊天档案。启动后确认左下角为 v0.5.1。内置 SSH 默认显示文件工作区；明确选择的 OpenSSH 兼容模式仍保留，文件入口可预填新内置连接，原终端保持连接。

## 验证与已知限制

- 261 项前端测试、118 项 Rust 测试通过；1 项既有 OpenSSH 环境测试默认跳过。UI 回归覆盖分屏、目录筛选、焦点与标签滚动。
- Windows EXE 的隔离 SSH/SFTP 服务验证自动目录、慢启动、PTY/Shell 拒绝、终端退出、真实上传/下载、目录与续传、取消和主机密钥变化。
- 经授权的实际 Linux 主机验证了登录、资源读取、目录导航和只读 SFTP 下载。远端 Windows 使用协议样本与本地 CIM 验证，不代表所有服务器、Windows/WebView2 组合均已验证。
- 文件管理要求服务端提供 SFTP；内置认证支持密码或显式私钥，MFA/SSH Agent 等可使用 OpenSSH 兼容终端。主机资源登录时读取，可手动刷新，不是连续实时监控。
- 续传与任务记录不跨应用重启；同名文件不覆盖，目录传输不跟随链接。AI 尚不能操作远端文件，Office 预览和浏览器扩展仍沿用原有兼容边界。
