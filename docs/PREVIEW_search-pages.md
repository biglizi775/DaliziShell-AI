# 在索引搜索中翻页

在工作区顶部选择 **含子目录** 或 **全部位置**，输入文件名或搜索表达式。超过 200 个匹配时，搜索框下方会显示当前范围、总匹配数和翻页控件。

- 点击上一页或下一页，也可以在搜索框按 **Page Up / Page Down**。要直接跳转，在页码框输入数字并按 **Enter**。
- **文件** 和 **文件夹** 筛选对整个搜索表达式生效。例如输入 `预算|报告` 并选择 **文件**，两个关键词都只返回文件。
- 翻页时保持本次查询的顺序、匹配数和条目，即使后台刚刚增删了索引记录。点击 **刷新结果** 会从最新索引重新查询并回到第一页。结果不足一页时仍会随索引更新自动补充。
- 在任一页都可以复制路径，或用文件夹按钮在新标签中定位。修改关键词、范围或类型会开始新的查询。关闭面板、切换目录或标签会释放原结果。

这里保存的是查询时的文件名及元数据。磁盘上的文件可能随后改名、移动或删除。底部状态显示索引进度与覆盖上限。当前目录的即时筛选继续直接使用已经打开的文件列表。

这版也修正了本地文件移动回执。Windows 将一个普通文件整体移动并返回实际目标时，应用会核对原路径已经消失、目标类型一致，再将该项记为完成。
