# 切换默认模型时保留已提交的对话

在目录 A 提问后，可以切到目录 B，在输入区选择另一个模型或通过设置更改服务。A 的自动摘要、普通回答和项目计划继续使用提交时选定的模型。B 的下一条消息使用新的默认设置。等待时和收到回答后都可以在当前对话中看到该轮模型，悬停可查看服务地址。

如果 A 收到一份待确认的文件计划，回到 A 可以查看和执行原计划，也可以放弃。选择新模型不会延长计划的有效期。要停止 A 正在进行的请求，请在 A 点击「停止」。在 A 再次提问时，新模型将按当前设置收到 A 的近期聊天、摘要及启用的项目资料。

服务地址或 API 格式改变后，表单会清空临时密钥。新接口可以使用自己已保存的 Windows 凭据，也可以输入单独的密钥。本次运行显示的模型标签只用于当前会话；旧版兼容的聊天档案继续保存正文与操作步骤。
