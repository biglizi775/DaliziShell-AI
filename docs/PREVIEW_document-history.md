# 核对保存回复与撤销修改

把 Agent 回复存为项目文档后，回到当时的本地目录，打开「Agent → 文件操作记录」，选择标有「保存回复」的文件。可以看到目标路径、结果和耗时。遇到同名文件时，保存窗口保留草稿，改名后可以再次提交。两次操作分别记录。

如果撤销前有人手动修改了文件，程序会保留当前内容，在记录里说明原因。聊天中的「撤销这次修改」和本地文件右键的「撤销上次 Agent 修改」都能留下记录。对话临时关闭或程序重启后，可从原目录重新打开。

遇到「结果待核对」时，先查看目标文件的实际内容，再决定是否重新提交。移除记录只清理日志。同一目录的文件计划、保存回复和撤销修改合计最多 128 条。

本版兼容之前的本地文件计划记录。新产生的保存回复与撤销记录使用第二版格式，请用本版或后续兼容版本查看。Harness 任务与 SFTP 传输仍从各自的面板进入。
