# 从工作目录核对任务与传输

在 Agent 面板选择「工作区历史」。本地目录有三个入口：文件操作、Harness 任务和 SFTP 传输。Harness 问答或修改任务可以直接打开对应的结果。选择传输记录可以查看本地路径、远程路径、主机指纹、时间和结果。

比如把一个本地文档上传以后，可以关闭 SSH，在原本地目录打开记录。也可以在原连接的远程文件面板点「工作区历史」，查看同一项传输。主机指纹发生变化时，新连接会使用独立的远程历史。

如果传输时程序意外退出，已开始的项目可能显示「结果待核对」。先检查两端文件，再决定是否重新传输。历史里的操作只用于查看或清理记录。暂停、取消、重试和临时文件清理继续使用传输任务面板。排队但尚未启动的项目仍属于本次运行。

传输记录保存在本机应用数据目录。完整解压本预览包后运行 DaliziFiles.exe，可从原目录查看已有的文件操作与 Harness 任务。旧版本没有持久化 SFTP 传输，新版从第一次新传输开始记录。
