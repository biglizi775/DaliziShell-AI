# 本地对话的角色与技能

打开本地目录的 Agent 对话，在顶部选择通用、文件整理、产品与设计、开发、审查、终端与远程、网页或电脑操作助手。展开「本轮技能」查看当前角色的用途、将发送的技能和可选推荐。

推荐默认关闭。勾选「本对话采用角色推荐技能」后，程序会在手动启用的技能后补入该角色的内置技能，每轮合计最多 4 项。已占满名额时，额外的推荐会列在「待加入」中。你可以打开「技能」调整手动选择。

审查使用只读权限。终端与远程、网页、电脑操作根据你提供的材料给建议，项目工具会关闭。切回其他角色后，仍保留只读权限。需要文件操作时，手动开启项目工具并选择权限。

切换角色或推荐开关后，待执行计划和切换前发出、切换后返回的计划均需重新生成。已开始执行的任务继续按原计划完成。可以切回其他目录继续那里的对话。新建对话或恢复档案后，角色从通用助手开始，推荐关闭。回复的角色标记保留在本次活动对话中。
