# 开发预览：退出程序前保存对话

点击标题栏关闭按钮、按 Alt+F4 或选择托盘“退出程序”后，程序会检查所有已打开的 Agent 对话，包括后台文件夹和固定项目。写入完成后窗口才会关闭。如果窗口原先收在托盘，选择退出会显示主窗口，方便处理保存问题。

例如，文件夹 A 的记录被另一个窗口修改，固定项目 B 的回复还在生成。退出时会显示 A 的标题、目录和错误。选择“保留并返回”可以继续在原窗口工作，B 的回复也能继续接收。选择“另存为新对话”，会在 A 中保留两个版本。接着程序结束 B 的请求，将已收到的文字标为“未完成的回复”，根据该对话的保存设置写入 B 的记录。

如果普通 Agent 的文件操作正在执行，窗口会提示所属目录。等操作返回后可再次退出。手动保存已经开始时，退出会等到这次写入完成。进度窗口上的“暂不退出”可取消退出，已经发出的保存请求仍会完成。

输入框里尚未发送的草稿，以及关闭自动保存且未点保存的临时对话，仍只放在内存中。希望留存时请先复制草稿或手动保存对话。强制结束进程和断电不会经过窗口关闭流程。

本预览沿用上一版的[对话保存恢复选项](PREVIEW_archive-recovery.md)，正式发行验收使用[冻结的 M5 候选](HARNESS_M5.md)。
