# M3 · 把网页选中的文字引用到项目

适用于已启用 Harness 的 Windows 开发构建及 [M5 候选包](HARNESS_M5.md)。假设你在网页 X 上读到一段接口说明，想让 Agent 解释，并将回答留在项目 A。选区是资料来源，A 是任务归属；两者都在发送前显示。即使随后打开网页 Y、关闭 X 或切换到另一个项目，已经采集的文字和回答的归属都不变。

## 第一次使用

1. 按 [M1 模型配置](HARNESS_M1.md)设置可用的 Messages 服务和模型。在工作台的 **Web** 标签打开 HTTP(S) 网页，在正文中选中文字，右键选择 **引用到项目 / Quote to project**。
2. 预览会列出本次选中的完整文字、来源地址和采集时间。来源地址去掉了查询参数及 `#` 片段；域名、路径和选中文字仍会交给所选服务。请在这里核对内容。
3. 在「保存问答的项目」中明确选一个本地目录，或点击「选择其他目录…」。打开、保存或固定过的目录可以出现在候选项中，但不会自动选中。点击「核对目标和模型」，检查实际项目路径、服务地址和模型。
4. 输入问题，点击「发送选区和问题」。只有这一步会启动模型请求。回到所选目录的 **文件任务 → 任务记录** 查看回答，也可以在任务记录中显式查看所有目录。关闭预览会放弃未提交的引用，不会更改固定项目。

## 可引用的内容

| 情况 | 行为 |
| --- | --- |
| 主页面的普通正文 | 单次最多 32 KiB，按 UTF-8 字节数计算，超过后请缩短选区；不会悄悄截断。 |
| 没有选中文字，或选中表单、可编辑区域、嵌入框架里的文字 | 不提供引用菜单。网页自己替换了右键菜单时，也可能看不到入口。检查「设置 → 浏览器设置 → 网页行为 → 右键菜单」是否开启。 |
| 页面含嵌入框架，WebView2 无法区分主文档与框架 | 保守地隐藏入口，包括部分页面的主正文。不会改用剪贴板或读取整页来猜测来源。 |
| 打开菜单后，点击引用前已经跳页、切走或关闭标签 | 旧选区失效。回到所需页面重新选中文字。已经弹出预览后，跳页或关闭原标签不会改变预览。 |
| 五分钟内未提交、关闭预览或退出应用 | 需要重新选择。未提交的选区不作为历史草稿恢复。 |

## 数据与迁移

以下索引说明对应 M3；包含 [M4 远程问答](HARNESS_M4.md)的开发版会从 v3 导入 v4。

模型在这个只读任务中收到问题、选区正文、经过上述处理的 URL 和采集时间，工具清单为空。不会附带项目文件、网页其他正文、表单、Cookie、浏览历史或 SSH 会话。模型仍可能在回答中复述引用。

任务索引保存在应用数据目录的 `HarnessTasks/tasks-v3.json`。索引记录项目身份、问题、回答、模型和网页来源元数据，不单独存储选区全文。升级时优先读 v3；如不存在，先找 v2，再找 v1。迁移保留旧索引；旧版本只能看到其自己的历史。发现现有索引损坏时报错并保留原文件，避免用旧数据掩盖问题。主动移除一条历史时会清理现存旧索引中的同一条记录。

## 实现与验收

- [原生采集](../src-tauri/src/browser_reference.rs)使用 [WebView2 右键菜单目标接口](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2contextmenutarget)检查选区、可编辑状态和来源。在用户选择原生菜单项时才读取选中文字；原生页面和标签身份必须仍然匹配。网页没有获得宿主命令权限。
- [项目预览](../ui/harness-web.js)和[任务宿主](../src-tauri/src/harness_tasks.rs)分别负责展示与核验。提交前宿主再次核对本地目录身份；网页任务只允许问答，不能借引用获得目标目录的读取或写入权限。
- [原生场景](../src-tauri/src/harness_web_tests.rs)启动实际的 Tauri 主窗口和子 WebView2，在独立应用配置中检查输入框、同地址 iframe、过期菜单、页面导航、关标签、显式项目选择、页面不能操作受保护命令，以及最终任务记录。[本机模型端](../tools/harness_m3.cjs)检查真正经过 dsh 的请求，有且仅有一次，包含 X 的选区，不含 Y 的正文、未选文字、私有查询参数或本地文件。测试不需要云端密钥，不证明某个线上模型或任意第三方网站可用。

已有 [M1 文档](HARNESS_M1.md)所需的本地开发运行时后，在仓库根目录执行：

```powershell
# 只验收 M3；最后一个参数是可复用的 Cargo 输出目录
node tools/harness_m3.cjs stable-x86_64-pc-windows-msvc src-tauri/target/msvc-dev
# 全部桌面回归还包括 M4 双主机场景，请按 M4 文档先准备 Python/Paramiko
.\tools\verify_harness_desktop.ps1 -Toolchain stable-x86_64-pc-windows-msvc
```
