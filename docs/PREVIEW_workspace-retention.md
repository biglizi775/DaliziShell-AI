# 开发预览：来回浏览目录，保留手头的工作

在标签 A 写下草稿，或让 Agent 生成一份需要确认的文件操作计划。随后打开其他目录、网页或 SSH 标签，再回到原来的标签和目录：草稿仍在原输入框，原计划仍可审阅。同一个目录的两个文件标签各自保留草稿；固定项目时仍沿用项目自己的对话。

系统通常保留 24 组会话。草稿、显式引用、只读设置、待处理的计划、待确认的记忆建议、仍可撤销的文档修改和未保存的对话都不会被空闲目录挤掉。未完成的工作多于 24 组时会暂时超出；在后续浏览时，已经清空或妥善保存且没有待处理操作的会话可以回收。草稿不进磁盘，重启后不会恢复；在「跟随当前标签目录」模式中，主动关闭所属标签也会释放它的草稿。

普通项目工具的文件操作计划沿用后端原有的 15 分钟有效期。计划到期后标为未执行，需要时重新生成；切回原标签不会延长时限，也不会再次调用模型。这与独立「文件任务」中的 Harness 任务记录是两套生命周期。
