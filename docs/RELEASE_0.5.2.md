# Dalizi Files v0.5.2

2026-11-18 · Windows x64 · 收束为文件、SSH 与网页工作台

这一版把工作台收成三块：文件、终端/SSH、网页。内置 AI 助手不再随程序提供，避免在对话、文件和浏览器之间来回切换、复制。文件浏览、PowerShell、SSH/SFTP 和网页标签仍在同一个窗口。

## 优化点

- **去掉内置 AI。** 删除右侧对话面板、模型接口、技能、记忆、角色、网页助手和 Harness 任务引擎。设置页不再有「智能体」；快捷操作、文件右键、网页右键和 SSH 文件面板里的 AI 入口一并去掉。
- **旧数据留在原地。** `DaliziData/preferences.json` 仍可读取，其中的模型接口和 AI 面板设置会被忽略，下次保存时去掉。工作目录 `.dalizi/` 里的聊天档案和记忆、凭据管理器里的模型密钥不读取，也不删除。
- **SSH 传输记录按当前目录查看。** 远程文件面板的「传输记录」只列出这条连接、这个账户和当前远程目录的 SFTP 传输。记录保存在本机，重启后仍可核对。
- **本地目录和远程目录可以对照。** 内置 SSH 标签可打开双栏，左侧选本地目录，右侧进入远程目录，再核对后上传或下载。
- **从当前标签打开它所在的目录。** 在文件夹标签点「＋」打开同一目录；在 PowerShell 标签点「＋」打开该终端的启动目录。网页和 SSH 没有本地目录时，打开「此电脑」。
- **网页链接可以交给本程序。** 在「设置 → 浏览器设置 → 外部应用链接」登记当前 EXE，再到 Windows 默认应用里为 HTTP 和 HTTPS 选择 Dalizi Files。程序不会自己变成默认浏览器。只处理这两种网址，不关联磁盘上的 `.html` / `.htm` 文件；指定用其他浏览器的程序不受影响。
- **沿用 0.5.1 的 SSH 工作区。** 登录后仍默认显示概况、终端和远程目录；终端异常不会关掉 SFTP。标签栏的滚轮和滚动条保持可用。

## 下载与升级

下载附件 `dalizi-files-0.5.2-windows-x64.zip`，完整解压后运行 `DaliziFiles.exe`。附带许可证、使用说明、历史更新记录、构建信息与 SHA-256 校验；GitHub 自动生成的 Source code 用于开发，不能直接运行。

需要 Windows 10 1809+ / Windows 11 x64 与 Microsoft Edge WebView2 Runtime，无需安装 Rust、Node.js 或 Python。发行包尚未签名。

升级前退出旧程序，保留原有 `DaliziData/` 配置。启动后确认左下角为 v0.5.2。SSH 连接、主机信任和已记住的登录凭据仍可使用。若要把网页链接交给本程序，EXE 请放在固定目录后再登记；以后移动了程序，需要重新登记。

## 已知限制

- 文件管理要求服务端提供 SFTP。内置认证支持密码或显式 OpenSSH 私钥；多因素认证、硬件密钥和 SSH Agent 请使用 OpenSSH 兼容终端。
- 续传与未完成任务不跨应用重启自动继续。传输记录可以在重启后查看；同名文件不覆盖，目录传输不跟随链接。
- 登记 HTTP/HTTPS 后，仍要在 Windows 设置里分别选择。写死 Edge 或使用 `microsoft-edge:` 的链接不会打开本程序。
- Office 预览、浏览器扩展和 WebView2 版本差异沿用原有兼容边界。旧版 WebView2 109 可以浏览网页，但不能管理扩展。
