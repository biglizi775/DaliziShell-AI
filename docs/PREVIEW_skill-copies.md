# 把内置技能改成自己的版本

例如，要让文件整理助手遵循团队的命名规则，打开本地 Agent 对话上方的「技能」，在「文件整理」卡片选择「创建自定义副本」。可以直接在现有说明中添加规则。保存后的副本位于「我的技能」，初始为停用。需要使用时，勾选「用于对话」。

副本显示来源和版本号，应用升级后继续使用保存的正文。使用「编辑副本」可以修改当前版本；使用「另存为副本」会增加一份停用的独立版本。导入项和副本合计最多 32 个，每轮仍最多使用 4 个技能。

开启角色推荐后，手动启用的副本可以满足对应原技能的推荐。只有明确手动启用两者时，两者才会一起发送。已经发给模型的请求沿用发送时的技能正文，后续消息读取最新保存的内容。

其他程序在编辑期间更新同一副本时，当前编辑器会保留草稿并显示冲突。可以另存一份，或取消后刷新技能列表。新旧版本的来源都已被移除时，可以先从编辑框复制草稿。
