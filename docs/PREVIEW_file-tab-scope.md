# 从当前标签打开目录

从文件夹点击标签栏的「＋」，新的文件标签打开同一目录。从 PowerShell 点击「＋」，打开该终端的启动目录。网页或 SSH 没有本地目录，从这些标签点击「＋」会打开「此电脑」。在后台标签上使用右键菜单时，以鼠标点中的标签为准。在网页内按 Ctrl+T 仍会打开新网页。

快捷操作面板只在已读出内容的本地目录提供「在此新建文件夹」。创建文件夹后立即切换目录，新文件夹留在发起操作的位置，后续重命名也只在原位置出现。

打开暂时不可用的目录时，标签会保留请求的地址和返回历史。可以切到别处，或退出后再回来。目录重新可用时点击「重试」即可。右侧对照面板独立保留它的目标，读取失败时清空旧文件列表，点击该面板的刷新按钮可重新读取。Agent 的跟随目录模式使用左侧工作目录；在右侧浏览或重试不会切换聊天项目。

工作台进程异常退出时，Windows 会结束已接入该工作台的 PowerShell 与 OpenSSH 终端进程。通过 PowerShell 独立启动的应用可以继续运行。
