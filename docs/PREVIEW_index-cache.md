# 开发预览：文件索引缓存占用时的保存

如果文件名或文件夹大小的缓存正在被其他程序短暂占用，以前后台索引可能放弃本次保存；这时退出再打开，可能仍读到上一次的索引。这版在 Windows 替换缓存失败时，使用已写完的临时文件再试，最多额外等待 185 毫秒。它不会重新扫描磁盘或再次写入整份索引。

如果目标持续被占用，旧缓存仍可读取，本次临时文件会清理；解除占用后，下次保存可以正常替换。这个改动只影响应用自己的两个索引缓存，不改用户文件和搜索语法。

本预览同时包含此前的[按目录清理文件任务](PREVIEW_workspace-history.md)。请完整解压到新目录，保留组件 ZIP；同一用户的各个预览使用相同的本地配置。正式验收仍以 [M5 冻结候选包](HARNESS_M5.md) 为准。
